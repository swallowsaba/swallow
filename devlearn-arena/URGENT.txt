【1】リロードで進捗が消える不具合
- 症状: 画面をリロードまたは開き直すと、学習の進捗・都市・プレイヤーの状態が消える
- 仕様: docs/architecture.md 5 章と docs/data-model.md 7 章のとおり、IndexedDB に自動保存し、
  リロード・ブラウザの再起動の後も全て元に戻ること
- 先に、リロードで消えることを再現する失敗するテストを書いてから直せ（CLAUDE.md 13 章）
- 自動保存のきっかけ（操作の 2 秒後、レッスンの段が進むたび）と、起動時の読み込みが働いているかを確かめろ
- 保存に失敗した時は、何が起きたかを画面に 1 行で知らせること

【2】レッスン画面のボタンの位置
- 症状: 「次へ」「戻る」が画面の右下にあり、問題・選択肢・端末などの操作は画面の中央にあるため、
  毎回マウスを大きく動かすことになる
- 直し方: 操作する場所と、次に進むボタンを近づける。
  左の段の中身（解説・理解・クイズ・結果・まとめ）の直下に「次へ」「戻る」を置く。
  右の図・模擬環境・端末を操作している時も、視線の移動が小さくなる位置にすること
- あわせて、キーボードだけでも進められるようにする（Enter で次へ、Backspace で戻る。
  端末に文字を打っている間は端末が優先）。docs/ui-design.md 4 章の表に足せ
- docs/ui-design.md 7 章のレッスン画面の図と説明を、直した配置に書き換えること

どちらも、直した後に node tools/shoot.mjs 相当の撮影で画面を確かめ、
npm run typecheck と npm run lint と npm run test を通してからコミットしろ。
