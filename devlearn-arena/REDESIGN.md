# 全面改修（街づくり × 学習の一体化）

**上から順に実装し、終えた項目を [x] にする。** 各項目のあと `npm run verify` を通す。最後に `npx playwright test --workers=1` と `npm run build`。
中断しても、このファイルの未完了の項目から再開する。

## 要件（ユーザー指示）

- 右上の「街」は不要。
- 全部、各カテゴリ（シェル / Git / GitHub / Kubernetes / ネットワーク）のウィンドウの中で、街全体を学びながら作っていく。
- 動線：全体図でカテゴリを選ぶ → 「説明・コマンド・街」が一つになった画面へ遷移。そこで詳細説明・コマンド・個別説明・街の創造を行う。
- 街のイメージは Cities: Skylines II のような街（区画・道路・車・住民・高さの違うビル群が育っていく）。硬い学習感を無くす。
- 説明や背景を聞かずにいきなりコマンド、にならない導線にする。
- ヒントボタンを押すとターミナルにヒントが出るのは NG。左上のパネルに出す。

## 設計

作業画面 `/world/:track`（外枠なし・1 枚）

- 上部：カテゴリ名、街の規模（住民・施設・格）、全体図へ戻る
- 左上：学習パネル。いまの段階に応じて中身が変わる
  1. 街の紹介（案内人の話）
  2. 施設の学習：住民の困りごと → 何なのか（街で例えると）→ なぜ必要か → 仕組み → 現場の落とし穴 → 判断問題 → 建設
  3. 任務の依頼：依頼の話 → 使う道具（コマンドの意味）→ 理解度チェック → 作業の段取り
  4. 作業：やること・通過条件・ヒント（ヒントはここに出す）
- 左下：ターミナル。施設を建てて依頼の話を聞くまでは操作できない（理由と、何をすればよいかを重ねて出す）
- 右：街（アイソメトリック）と、いまの状態の図を切り替え。説明中は街、作業中は状態の図が既定
- 街：施設ごとの地区。建てると名所が建ち、任務をこなすほど地区に住宅・商業・工業のビルが増えて高くなる。道路を車が走り、住民が増える

`/` と `/?mission=` は作業画面へ転送。全体図の島を押すと作業画面へ。
