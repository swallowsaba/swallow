# 見た目の基準（3D 版）

**目標は Cities: Skylines II のような 3D の街。** 過去の指示にあった
「SVG で描け」「3D ライブラリを入れるな」「斜め45度にしない」は**すべて撤回する。**
WebGL で本物の 3D として描く。

## 1. 使うもの

- **three.js**（`npm i three` と `npm i -D @types/three`）。CDN からは読まない。バンドルに含める
- 追加で入れてよいもの: `@react-three/fiber`（React から three を扱う）、
  `@react-three/drei`（カメラ操作・影・補助）
- 外部から 3D モデル（glTF）を取ってこない。**形は全てコードで組み立てる**
  （オフラインで動くこと、GitHub Pages に置けることが条件）
- 初回読み込みを抑えるため、3D 部分は `React.lazy` で遅延読み込みにする

## 2. カメラと操作

- 斜め俯瞰の固定角（水平から約 35 度）。`PerspectiveCamera`、視野角 45
- `OrbitControls` を使い、**回転は水平方向のみ**（`minPolarAngle` と `maxPolarAngle` を同じ値に近づける）。
  真下や真横を向けない
- ホイールで寄り引き、右ドラッグで平行移動、ダブルクリックで全体表示
- 注目点へ寄るときは 0.6 秒で補間する（瞬間移動させない）

## 3. 光と影

- `DirectionalLight` 1つを太陽とし、影を落とす（`castShadow`、`shadowMap` は PCFSoft）
- `AmbientLight` か `HemisphereLight` で空の色を回り込ませる（青みのある間接光）
- 建物・木・地面はすべて `castShadow` と `receiveShadow` を持つ
- 時間帯の概念を持たせる。夜は窓が光る（`emissive` を使う）
- `fog` を薄く掛けて遠景を沈ませる

## 4. 地面と道路

- 地面は平らな板1枚ではなく、**タイルの集合**にする。1タイル 8m 四方
- 草地・舗装・土を材質で塗り分ける。草地には低いポリゴンの起伏を持たせる
- 道路は押し出したメッシュ。**縁石・車線の白線・横断歩道**を持つ
- 交差点では道が繋がる。行き止まりは作らない
- 未解放の区域は暗く沈め、輪郭だけ見せる

## 5. 建物の作り方

**モデルを外部から取らず、パラメータから組み立てる。** `src/city3d/buildings.ts` に置く。

```ts
export interface BuildingParams {
  kind: 'tower' | 'midrise' | 'house' | 'monument' | 'depot';
  footprint: { w: number; d: number };   // メートル
  floors: number;                         // 階数
  setbacks: number[];                     // 何階目で幅を絞るか
  roof: 'flat' | 'gable' | 'hip';
  seed: number;                           // 見た目の振れ幅。乱数ではなく seed から決める
}
export function buildMesh(params: BuildingParams): THREE.Group;   // 純粋関数
```

1棟の中に必ず含めるもの。

- 基壇（一段太い足元）
- 本体。階ごとに**窓の帯**を作る。窓は `InstancedMesh` でまとめる
- セットバック（高層は上へ行くほど細くなる）
- 屋上設備（貯水槽・空調・アンテナ・パラペット）を2つ以上
- 入口（扉と庇）
- 高さ方向に材質を変える（低層は石、上層はガラス）

**窓は1棟あたり 40 枚以上。** 灯っている窓と暗い窓を混ぜる。
灯りは `emissive` で表現し、稼働状態と結び付ける（Running の Pod がいる階は灯る）。

## 6. 街の密度

- 建物の周りに必ず置くもの: 街路樹、街灯、生垣、ベンチ、柵、看板
- 木は幹＋葉の塊3つ以上。`InstancedMesh` で数百本置く
- 車と人は `InstancedMesh` で動かす。道に沿って走らせる
- **地面がむき出しのまま残っている状態を不合格とする**

## 7. 色

`src/city3d/palette.ts` に定義し、全てそこから引く。

| 用途 | 色 |

| 舗装 | `#8e8e8a` |
| 土 | `#a08a62` |
| 水 | `#4f7fa3` |

## 8. 性能

- 同じ形はすべて `InstancedMesh` にまとめる。1棟ごとに個別のメッシュを作らない
- 描画呼び出しは 200 以下に収める
- 遠くの建物は窓を省く（LOD）
- 60fps を保つ。維持できないときは影の解像度を落とす

## 9. 学習内容との対応（変えない）

| 学ぶ対象 | 街での姿 |

| k8s のノード | 高層ビル。建設はアニメーションで段階的に |
| k8s の Pod | ビルの中の住人。階の窓が灯る。別ノードへ移ると引っ越す |
| k8s の Service | バス停。Endpoints に載った Pod のいるビルへバス路線 |
| git のコミット | 記念碑が歴史通りに並ぶ |
| git のブランチ | 通りが分岐し、マージで合流 |
| git の index | 倉庫。`add` で荷物が家から倉庫へ運ばれる |
| ネットワークの機器 | 施設。リンクは道路。パケットは走る車 |
| GitHub の PR | 市役所。承認が揃うと門が開く |

## 10. 実装の指定

- 3D は `src/city3d/` に隔離する。React に依存しないのは
  `model.ts`（状態→街のデータ）と `buildings.ts`（パラメータ→形）
- **状態から街を導く部分は純粋関数**。同じ状態からは必ず同じ街になる。
  乱数は使わず seed から決める。テストする
- 描画部分（`CityScene.tsx`）はデータを受け取って描くだけ
- `prefers-reduced-motion` のときはアニメーションを即時にする
- WebGL が使えない環境では、簡易な 2D の一覧に落とす（真っ白にしない）

## 11. 曲線（直線だけの街は不合格）

格子に箱を並べただけの街は不合格。次を必ず入れる。

- **陸地の輪郭は曲線。** 四角や菱形の地盤にしない。波打つ海岸線にする
- **川を蛇行させる。** 中心線をスプラインで作り、幅を持たせたリボンとして描く。岸に砂の帯を付ける
- **道路が川を渡る所には橋を架ける**
- **大通りは弧を描く。** 格子の道路とは別に、曲線の幹線道路を最低1本通す
- **主要な交差点はロータリーにする**（円形の環道と中央の緑地）
- **公園には曲がった小道と池を置く**
- **建物の形を混ぜる。** 箱型だけでなく円柱の高層ビルを入れ、曲面に沿って明るさを変える。
  低層の住宅には切妻屋根を載せる
- 木の葉は丸い塊を重ねる
- 曲線は three.js の `CatmullRomCurve3` と `TubeGeometry` / `ExtrudeGeometry`、
  円柱は `CylinderGeometry`（分割数 24 以上）で作る
- これらの配置も seed から決定論的に導く
