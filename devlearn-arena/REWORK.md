## 1. 学びの流れを全任務に入れる（最重要）

いまは「Kubernetes は、何台ものコンピュータを…」と文章で説明し、すぐコマンドを打たせている。
何のために打つのか分からず、学習感が無い。**全任務を `CLAUDE.md` の5段の流れに作り直す。**

- [x] 1-1. `LessonDefinition` に5段を持たせる型を入れる。
  ```ts
  experience: ExperienceScene;   // 1. 体験（コマンド無しで遊ぶ）
  reveal: RevealScene;           // 2. 登場（仕組みが施設として現れる。用語はここで出す）
  quiz: CityQuiz[];              // 3. 確かめ（街の中で答える。1〜2 問）
  steps: LessonStep[];           // 4. 操作（各手順に purpose と afterward を必須）
  recap: Recap;                  // 5. 振り返り（前後比較と3行のまとめ）
  ```
  `LessonStep` に `purpose: string`（この操作で何を確かめるか）と
  `afterward: string`（打った後に街で何が起きたか）を**必須**で追加する。

- [x] 1-2. **体験の場面**を作る。`src/lesson/experience/` に置く。コマンドは使わない。マウスで遊ぶ。
  最低これだけ作る。
  | 任務の分野 | 体験で困ること |
  |---|---|
  | シェル | 住所の分からない街で荷物を届ける。住所（パス）が無いと迷う |
  | Git | 何度も書き直した設計図。どれが昨日の版か分からなくなる。前に戻したいのに戻せない |
  | Kubernetes | 住人（アプリ）が次々に来る。手で空きビルへ案内する。停電したビルの住人を手で引っ越させる。手が追いつかない |
  | ネットワーク | 荷車を隣の町へ送りたいが、道も案内板も無い |
  | GitHub | 大勢で同じ設計図を直すと、互いの変更を上書きしてしまう |

- [x] 1-3. 体験が終わると**登場**の段へ。仕組みが施設として街に建ち、カメラが寄り、
  「さっきあなたが手でやっていたことを、代わりにやる施設」と紹介する。
  用語はここで初めて出し、いま映っている建物・住人に矢印で結び付けて説明する。

- [x] 1-4. **クイズを復活させる。** 文字の選択肢だけにしない。街の中で答える形を主にする。
  - 「住人が入っているビル（ノード）をクリックせよ」
  - 「Pod が Running になるまでの順番に、札を並べよ」
  - 「バス（Service）が停まる住人を全部選べ」
  正解すると街が育つ。外れたら理由を図で示し、もう一度答えられる。

- [x] 1-5. 操作の段では、各手順の札に**先に目的を1行**出す（`purpose`）。
  打った後、**街で起きたことを1行**返し、該当する建物にカメラを寄せる（`afterward`）。

- [x] 1-6. **全任務を作り直す。** 既存の任務すべてに5段を入れる。
- [x] 1-7. テスト `src/lesson/flow.test.ts`。
  - 全任務が5段を持つ
  - 全手順が `purpose` と `afterward` を持つ
  - 用語辞書の語が、その任務の `reveal` より前（`experience`）の文言に出てこない
  - 全任務が1問以上のクイズを持ち、そのうち1問以上が街の中で答える形である

## 3. 動いていない・壊れているもの

- [x] 3-1. **車と人が動いていない（3回目の指摘）。** 原因を特定してから直す。
  - 描画の毎フレームで、車の `InstancedMesh` の行列を更新しているか。`needsUpdate` を立てているか
  - 更新関数が実際に呼ばれているか（`grep` で呼び出し元を確かめる。CLAUDE.md の「繋がっているか」）
  - **自動検査を作る**: `tools/shoot.mjs` を拡張し、同じ画面を 2 秒あけて 2 枚撮り、
    画素の差が一定以上あることを確かめる `tools/motion-check.mjs` を作る。差が無ければ失敗とする
- [x] 3-2. **Tab 補完の後、キーを打つたびに補完が走る。** 端末で `grep localhost rep` の途中で Tab を押すと、
  その後の打鍵ごとに同じ行が何度も出力され、`>` の継続行に落ちる。
  先に再現する失敗するテストを書いてから直す（`src/features/terminal/` と `src/engines/kernel/lineEditor.ts`）。
  Tab は1回だけ補完し、以後の打鍵は普通に文字を足すこと。
- [ ] 3-3. **端末の横幅を変えられない。** 端末と街の間に、ドラッグで動かせる縦の仕切りを入れる。
  幅は保存する。最小 320px、最大は画面の 60%。
