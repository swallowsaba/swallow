# 作り直し指示（第8版）

**先に `CLAUDE.md` を読むこと。** そこの規則が全ての作業に優先する。
上から順に実装し、終えた項目を [x] にしてコミットする。確認を求めず、止まらない。

## 目指すもの

参考は PGSimCity（https://nikolays.github.io/PGSimCity/）。**街が仕組みの模型として動き、
説明はその動きに寄り添って理解を助ける。** 次の4つを持つことが合格の条件。

1. **案内ツアー** … カメラが施設を順に巡り、各施設で「これは何か」を平易な言葉で示す
2. **コマンドの旅路** … 打ったコマンドが街の中をどう進むかを、カメラが追いかけて見せる
3. **施設の中身** … どの建物をクリックしても、それが何で、いまどういう状態かが分かる
4. **壊して直す** … 障害を起こすと街が反応し、学習者がコマンドで直す。失敗できるから学べる

## 6. 「なぜ」を遊べる図解にする

**見ているだけの図解は不合格。** 学習者が図の中で手を出し、仕組みが反応する「小さな遊び場」にする。

- [ ] 6-1. 「なぜ」の引き出しは、**文章ではなく遊べる図解を主にする。** 文章は図の下に3行まで。

- [ ] 6-2. 図解は `src/lesson/diagrams/` に置く React コンポーネント。**全て次の4つを持つ。**
  1. **操作できる**：図の中の要素をクリック・ドラッグ・つまみで動かせる
  2. **本物の仕組みで反応する**：台本のアニメーションではなく、既存のエンジン
     （`src/engines/k8s` `git` `net`）を小さく動かして、その状態を描く。だから嘘をつかない
  3. **操作に対応するコマンドを出す**：操作するたびに、図の下に
     「いまの操作 = `kubectl delete pod web-1`」と表示し、「端末で打つ」ボタンで左の端末に入力できる
  4. **小さな目標がある**：図の上に目標（例「住人を2人に戻せ」）。達成すると星が付き、光の粒が弾ける

- [ ] 6-3. 最低これだけ作る。

  | 識別子 | 遊び方 | 対応するコマンド |
  |---|---|---|
  | `pod-in-node` | Pod を別のビルへドラッグすると引っ越す。満員のビルには入れず理由が出る | `kubectl describe pod` |
  | `desired-vs-actual` | 住人をクリックで消すと、歯車が回って作り直される。replicas のつまみで数が増減 | `kubectl delete pod` / `kubectl scale` |
  | `pod-lifecycle` | 「時間を進める」を押すたびに Pending → ContainerCreating → Running が1段ずつ点灯。壊れたイメージを選ぶと再試行の間隔が伸びていく | `kubectl wait` / `kubectl run` |
  | `service-endpoints` | Pod のラベルを付け替えると、Service からの線が付いたり消えたりする | `kubectl label` / `kubectl set selector` |
  | `git-three-areas` | ファイルの札をドラッグして作業ツリー → インデックス → コミットへ運ぶ | `git add` / `git commit` |
  | `packet-hops` | 機器を選んで送ると、パケットが1ホップずつ渡り TTL が減る。線をクリックで切ると途中で止まる | `ping` / `ip link set down` |

- [ ] 6-4. 手触り。
  - 操作には必ず動きで応える（瞬間的に切り替えない）
  - 成功したら光の粒と、数字が回って増える演出
  - 失敗や制約（満員・未解放）は赤く揺れて理由を出す。罰はしない
  - 見た目は `docs/design/hud-mockup.html` の水準（暗い地、光る線、立体感）

- [ ] 6-5. 全ての任務の全ての手順が、いずれかの図解を持つ（`step.diagram`）。テストで検証する。

  - 目標の判定関数があり、達成できる操作列が存在すること

- [ ] 6-7. 撮影して、動きと操作の結果を自分の目で確かめる（操作前と操作後の2枚）。

## 7. 街を動かす

- [ ] 7-1. **車を作り直す。** 箱1つを禁止する。車体・運転席（窓付き）・タイヤ4つ・前照灯を持たせる。
  色は数種類。`src/city3d/vehicles.ts` に置き、部品数が 7 以上であることをテストする。
- [ ] 7-2. **車と人を常に動かす。** 道路の中心線に沿って走らせ、交差点で曲がる。
  人は歩道を歩く。時間を止めている間は止まる。
  テスト: 車の位置を計算する純粋関数に tick を与え、1 tick で位置が変わること。
- [ ] 7-3. **学習の操作と街を連動させる。** 最低これだけ。
  - Pod が作られる → 住人が道を歩いてビルに入る
  - Pod が Running になる → そのビルの窓が灯る
  - Pod が消される → 住人がビルから出て消える
  - Pod が作り直される → 新しい住人が歩いてくる
  - `kubectl wait` で時間を進める → 車と人の動きが速くなる
