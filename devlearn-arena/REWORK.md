## 1. 画面の構成を CS2 型にする

`docs/design/hud-mockup.html` の通りにする。**左の学習パネルは廃止。画面全体が街。**

- [x] 1-1. 画面全体を 3D の街にする。その上に HUD を重ねる。
- [x] 1-2. **端末は左に常駐**（幅 440px、上の帯の下から画面下端まで）。常に入力できる。
- [x] 1-3. **上の帯**（高さ 56px）。左に市の名前と日付、中央に指標を4つ
  （住人＝稼働 Pod 数 / 経験値 / 健全度 / 建築権）、右にマイルストーンの進み具合と速度操作。
- [x] 1-4. **課題の札**。端末の右、上の帯の下に幅 330px で重ねる。
  見出し・2行以内の説明・チェック項目（それぞれに対応するコマンド名を右に小さく）・報酬・ヒントボタン。
  **説明は2行まで。** 長い解説はここに書かない。
- [x] 1-5. **建物の情報パネル**。街の建物をクリックすると右に開く（幅 340px）。
  名前・種別・レベル、タブ（概要／住人／記録）、使用量の棒、住人の一覧、
  操作ボタン（**ボタンに実行されるコマンドを併記**し、押すと端末に入力されて実行される）。
- [x] 1-6. 選んだ建物の上に、光る輪と名札を立てる。
- [x] 1-7. **下の建設メニュー**。道路・区画・住宅・オフィス・記念碑・倉庫・市役所・中継塔。
  未解放のものは暗くして「M4 で解放」と出す。選ぶと上に種類の引き出しが開く。
- [x] 1-8. **右下の情報表示の切り替え**。住人の状態／バス路線（Endpoints）／交通（パケット）／系譜（Git）。
  選ぶと街の上に色で重ねる（CS2 の情報ビュー）。
- [x] 1-9. **住人の声**（CS2 の Chirper）。Pod の出来事を住人のつぶやきとして流す。
  感嘆符を使わない、落ち着いた文体。
- [x] 1-10. 解説が必要な人のために、課題の札の「なぜ？」から開く**解説の引き出し**を用意する。
  開くかどうかは学習者が決める。**読まないと進めない作りにしない。**

## 2. 3D の街を直す

`docs/design/city-reference.png` の水準にする。

- [x] 2-1. **霧を薄くする。** 近景と中景ははっきり見えること。霧は地平線の近くだけに掛ける。
  `scene.fog` の near を街の半径の 2 倍以上にする。
- [x] 2-2. **初期のカメラは、いま学んでいる区域に寄せる。** 島全体を遠くから見下ろさない。
- [ ] 2-3. **海岸線を曲線にする。** 階段状（タイルの角が見える）を禁止する。
  輪郭は極座標のノイズで作った曲線を `Shape` から `ExtrudeGeometry` で押し出す。
- [ ] 2-4. `DESIGN.md` 第11節（川の蛇行・橋・弧を描く大通り・ロータリー・公園の小道と池・円柱のビル）を実装する。
- [ ] 2-5. 開始直後の更地でも、**建てられる区画を光らせて示す。** 何も無い島を見せるだけにしない。
- [ ] 2-6. テスト。海岸線の頂点列について、隣り合う3点のなす角が 150 度以上であること（階段状でない）。

- 出力をハードコードしない。状態機械から導出する

- 端末は常に使える
- テストを必ず書く
