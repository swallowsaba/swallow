# Git の街の遊び：設計図の書き直し

## 学ばせたいこと
コミット（記録）、履歴、ブランチ、元に戻す、インデックス（次に記録する物を選ぶ）

## 遊び
学習者は街の設計技師。1 枚の設計図を、依頼に応じて描き直していく。

1. 依頼が来るたびに設計図を直す（建物を足す・消す・動かす）。直した図は上書きされる
2. 依頼主が「3 つ前の案の方がよかった、戻して」と言う。上書きしたので戻せない
3. 2 つの依頼が同時に来る（公園案と駐車場案）。1 枚の図の上で両方を試すと、互いの変更が混ざって壊れる

## 学習者の行動
- 設計図の上で建物を置く・消す・動かす
- 図の写しを取る（取れる回数に制限がある）
- 写しから図を戻す

## 失敗
- 戻したい版の写しを取っていなかった: 依頼主が不満の札を出す
- 2 案が混ざった: 公園の中に駐車場が生える

## 達成
- 3 つの依頼を、戻しの要求も含めて全て満たす

## 次の「登場」へのつなぎ
「写しを取る」行為に名前が付く（コミット）。写しが時系列に並ぶ（履歴）。
2 案を別々の紙で試せる（ブランチ）。どの変更を次の写しに含めるかを選ぶ台（インデックス）。
