| ミッション | 関係する分野 | 模擬環境 | 手順 | 報酬（XP / 資金 / 記念碑） |
|---|---|---|---|---|
| Web サーバを構築せよ | linux・web・net | linux-server | 4 | 150 / 400 / 灯台の記念碑 |
| Git で変更を管理せよ | git | linux-basic | 4 | 150 / 450 / 枝分かれの樹 |
| HTTPS を有効にせよ | sec・web | linux-server | 3 | 200 / 450 / 鍵の門 |
| コンテナを起動せよ | ctr・docker | container-host | 2 | 200 / 700 / 積み荷の塔 |
| 障害原因を特定せよ | trouble・linux・web | linux-server | 4 | 250 / 450 / 火の見の鐘 |
| Kubernetes 上でアプリを動かせ | k8s・ctr | k8s-cluster | 3 | 300 / 800 / 舵輪の碑 |

  - 報酬の資金は、先頭の分野の施設を Lv2 に上げる 1 回分（`docs/game-design.md` 8 章）。達成すると、得た XP と同じ量の資金も入る（2 章）
  - 「必要な知識」（`knowledge`。`docs/decisions.md` D-15）と「おすすめのレッスン」を示す。受けるのに前提は要らない
  - 実戦はレッスンと同じ模擬環境。ミッションに要る物を足した（設定ファイルで待ち受けを決める Web サーバ・HTTPS の証明書の連鎖・コンテナのボリューム・git と k8s の状態の判定）
- **報酬**（`docs/decisions.md` D-13。未決 U-06 の判断 案 C）: XP・開発資金・景観（記念碑）。素材と `unlocks` は外した
  - 記念碑 6 種の SVG（`src/city/assets/props/`）。受け取った記念碑は建設メニューの「公園」の引き出しに出て（入口に数の札）、費用なしで置ける。取り壊すと、また置ける
- **ミッション一覧**（上の帯の「ミッション」）: 6 本の全てが並び、選ぶと都市の課題・必要な知識・おすすめのレッスン・報酬・できるようになることが出る。どれも「受ける」を押せる
- **ミッションの実戦**: 依頼を出した施設の中の景色で、手順と仮想端末。エラーの案内・3 段のヒント・途中で終える・再挑戦（初めの状態から）。結果の画面に、できたこと・打ったコマンド・受け取った報酬
- **施設に並ぶミッション**（`docs/decisions.md` D-14。未決 U-07 の判断 案 A）: 情報パネルに、その施設の分野を含むミッションを施設の Lv の数まで（先頭の分野がその施設の物から）。挑戦中のミッションはおすすめの欄にも出る
- **施設の Lv2〜Lv5 の SVG**: 分野の 15 施設 × 5 段（`src/city/assets/facilities/<施設>/lv<1-5>.svg`。`npm run svgs` で模型から作る）。Lv が上がるほど棟・高さ・細部が増える。全て 30KB 以内（最大 29.7KB）
- **アップグレード**（Phase 8 で作った規則）で上げると、その Lv の絵に替わる
- 撮影の台本 `SHOOT_SCRIPT=tools/scenarios/missions.mjs npm run shoot -- p9-end`
