# 至急 01: リロードで進捗が消える不具合と、レッスン画面のボタンの位置

記録した日: 2026-10-08

指示（URGENT.txt）の 2 件を、`docs/development-plan.md` の Phase より先に直した。

## 1. リロードで進捗が消える不具合

### 原因

保存データの形と行き来（`src/save/schema.ts` `saveData.ts` `migrations.ts`）はあったが、
それを IndexedDB に書く所・起動時に読む所が無かった。遊んでいる状態（`src/screens/session.ts`）は毎回、新しい都市と空の記録で作られていた。

### 再現するテスト（先に書いて、失敗を確かめた）

`src/save/autosave.test.ts`。同じ保存先から遊んでいる状態を開き直すことで、リロードを再現する。

- 学習・都市・途中の実戦・市長が、操作の 2 秒後に保存され、開き直すと全て元に戻る（学習で得た資金も都市に残る）
- 2 秒たつまでは書かない。レッスンの段が進んだ時は、2 秒を待たずにすぐ書く
- 初めて遊ぶ時は新しい都市と市長で始める
- 保存に失敗したら 1 行で知らせ、次の操作でもう一度保存する。直ったら知らせを消す
- 保存データが壊れていたら、写しを残してから新しく始め、1 行で知らせる（壊れた物で上書きして失わない）
- 止めた後は保存しない。待っている保存は flush で書き切れる

### 直したこと

- `src/save/autosave.ts`: 起動時の読み込み（`openSession`）と自動保存（`startAutosave`）。きっかけは操作の 2 秒後と、レッスンの段が進むたび（始めた・修了した時も含む）
- `src/save/idb.ts`: 保存先。IndexedDB の `devlearn-arena` データベース、`save` ストアの `current`。設定の写しを localStorage にも置く
- `src/lib/storage/idb.ts`: データベースの版を 2 に上げて `save` ストアを足した。別のタブが新しい版で開く時は閉じて譲る
- `src/main.tsx`: 保存データを読んでから描く。ページを離れる時・隠れた時に、待っている保存を書き切る
- `src/screens/SaveNotice.tsx`: 保存の問題を、上の帯のすぐ下の中央に 1 行で出す（どの画面でも。閉じられる）
- 都市と学習の状態は、保存から戻した値で始められるようにした（`createSession` `createCityStore` `createProgressStore`）
- `docs/data-model.md` 7 章に、起動時の読み込み・失敗の知らせ・壊れたデータの写し（`broken-<時刻>`）を書き足した

### 画面で確かめたこと

- `SHOOT_SCRIPT=tools/scenarios/reload.mjs npm run shoot -- reload-after`（1280×720）: 模擬の学習記録を与え、2 秒待ってリロードすると、
  学習の記録（15 本・修了 15 本・XP 1,684）が同じに戻った。上の帯の開発資金 3,184・XP 1,684・おすすめも戻っていた
- IndexedDB の書き込みをわざと失敗させて撮った（都市画面・レッスン画面）。「保存できなかった（QuotaExceededError）。記録はこの画面に残っている。次の操作で、もう一度保存する。」が 1 行で出る。
  初めは画面の下に置いたが、建設メニューとレッスンの下の帯に重なったので、上の帯のすぐ下に移した

## 2. レッスン画面のボタンの位置

### 直したこと

- 「次へ」「戻る」を下の帯から、左の窓の**段の中身の直下**へ移した。「次へ」は右端（右の図・端末に接する側）
- 左の窓は、段の中身（長ければ中で巻く）とボタンの欄に分けた。中身が短ければボタンは中身のすぐ下、長ければ窓の下端に留まる
- キーボード: Enter で次へ、Backspace で戻る（`src/screens/lesson/stepKeys.ts`）。押すのは段が置いたボタンそのもので、押せない「次へ」は進まない。
  端末（xterm）・入力欄・編集欄に打っている間はその欄が優先。Tab で選んだボタンの上の Enter はそのボタン。用語の小窓が開いている間は働かない
- ミッションの実戦の画面も同じ枠を使っているので、同じ置き方とキーにした
- `docs/ui-design.md` 4 章の表に Enter と Backspace を足し、7 章の図と説明を書き換えた

### テスト

`src/screens/lesson/LessonScreen.test.tsx` の「次へ・戻るの位置とキーボード」（先に書いて、失敗を確かめた）

- 「次へ」「戻る」は左の段の中身の直下にあり、下の帯には無い
- Enter で次へ、Backspace で戻る。解説を Enter だけで通すと理解の段へ進み、記録される。押せない「次へ」は Enter でも進まない
- 文字を打つ欄では Enter と Backspace はその欄のもの

`e2e/lesson-layout.spec.ts`（全レッスンを 1280×720 で開き、帯と窓とボタンが画面の幅に収まる）も通った。

### 画面で確かめたこと

`tools/scenarios/lesson.mjs`（1920×1080）・`practice.mjs`（1280×720）・`missions.mjs`（1280×720）で撮り、開いて確かめた。

- 解説・クイズ: ボタンが中身のすぐ下、右の図に接する所にある。クイズで選択肢を押してから「次の問題へ」までの動きが小さい
- 実戦（端末）: 左の窓の下端、端末の左の縁のすぐ横に「結果へ」。端末から目を大きく動かさずに押せる
- まとめ・ミッションの実戦と結果: 中身が長い時は中身だけが巻き、ボタンは窓の下端に見えている
- ブラウザで Enter を 2 回押すと「何か → 何に使うか」、Backspace で「なぜ必要か」に戻った
