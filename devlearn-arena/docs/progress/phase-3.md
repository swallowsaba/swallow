# Phase 3 建物の選択と施設の情報

記録した日: 2026-10-02

## 実装したこと

- 建物の選択（`src/city/pick.ts`）: 画面の点の下にある立体の輪郭（凸包）のうち、描く順で一番手前の物を選ぶ。背の高い建物の上の方を押してもその建物が選ばれる。
  都市画面では、左クリック（押して動かさずに離した時）で施設と区画の建物を選び、何も無い所なら選択を外す。Tab / Shift+Tab で施設を順に選び、その施設を画面の中央へ寄せる。Esc で閉じる。
  選んだ物の足元に金の枠（光は選択の意味のある所だけ）
- 情報パネル（`src/screens/city/InfoPanel.tsx`、中身は `infoPanelModel.ts`、規則は `src/city/facilityInfo.ts`）: 右、幅 360、最大 70%。docs/ui-design.md 5 章の順に
  名前・種類・レベル（次のレベルの条件: その分野のスキル段階と資金）/ 状態（稼働中・建設中（基礎・骨組み）・止まっている: 道路に面していない）/
  対応する分野とスキルの値（段階の名前と、何をしたからこの値か。コンテナ施設はコンテナと Docker の 2 分野）/
  ここで学ぶ（見本のレッスン名 3 つと「学習ライブラリで全部見る」。学習ライブラリは Phase 5 以降なので押せない印）/ ミッション（見本の名前）/ アップグレード（費用と、加わる見た目）。
  公園の類は、周りの区画への効き目を出す。区画の建物は、建物の名前・段・住む人や仕事の数・近くの公園と施設の数
- 見本のデータ: `content/domains.json`（16 分野と対応する施設・推奨前提・関連・次）、`content/preview.json`（各分野のレッスン名 3 つは docs/curriculum.md の表の上から、
  ミッション名は docs/game-design.md 8 章の例。Phase 5・9 で目録に置き換える）、`content/facilities.json` に Lv ごとに加わる見た目（docs/city-design.md 4 章）
- スキルの段階の表（`src/game/skill.ts`）。値の計算は Phase 4。アップグレードの費用（`upgradeCost`、建てた費用 × 上げた後のレベル ÷ 2）
- 名札の配置（`src/city/labels.ts`）: 優先（選んでいる施設・大きな施設）の高い順に、指す点の真上から近い順に位置を試し、他の名札・建物の輪郭・画面の UI（上の帯・建設メニュー・情報パネル・知らせ・表示切替）に重ならない最初の位置に置く。
  ずらした名札は引き出し線で結ぶ。置けない名札は小さくせずに間引く。名札は分野の色の帯・施設名・Lv
- 表示切替（`src/city/overlay.ts`、`src/screens/city/OverlayToggle.tsx`、右下）: 学習の進み（施設のマスを対応する分野のスキルで塗る。記録が無いうちは灰色）・
  人口（住宅の建物に住む人の多さ）・交通（車の道のりが通る多さを、道路の線に沿って塗る）・発展段階（今の範囲と次に晴れる範囲、次の段階までの技術力と都市規模）。凡例に単位か意味を添える
- 撮影の台本 `SHOOT_SCRIPT=tools/scenarios/inspect.mjs npm run shoot -- p3-end`: 町を作り、名札・クリックでの選択・Tab・区画の建物・表示切替 4 種・引いた眺めを撮り、
  残り 9 施設を画面の操作で置いて全施設を Tab でたどる。名札の重なりの数と、UI の面積の割合を測る

| # | 結果 | 確かめたこと |
|---|---|---|
| V1 | 合格 | 常時の UI は画面の 7.9%（上の帯・建設メニュー・表示切替・知らせ）。情報パネルを開いても 19.5%（2 分野の施設で 19.8%）で、都市は 80% 以上見えている（台本が 2 画素の格子で実測） |
| V7 | 合格 | 情報パネルは見出しで区切った 1 枚の窓で、札を並べていない。並ぶ項目はレッスン 3・ミッション 3 まで。表示切替のボタンは 4 つ |
| V9 | 合格 | 常時の UI は 7.9%（20% 以内）。情報パネルは建物を選んだ時だけ出る |
| V10 | 合格 | 名札どうしの重なりは全ての撮影で 0。名札は建物の立体の輪郭を避けて置き、ずれた名札は引き出し線で建物と結ぶ。引いた眺め（`p3-far.png`）でも重ならない。1280×720 では知らせに隠れそうな名札を間引いた |

性能: 町の規模（描いた物 476）に名札と情報パネルを出したまま、1920×1080 で 59.9fps（Playwright の Chromium）。

気づいて直したこと:

- 交通の表示がマスごとに塗っていたため、曲線の道路の脇のマスまで階段状に塗られた → 道路の線に沿って塗る形に変えた（先にテストで再現）
- 1280×720 で、一時停止と「町に発展した」の知らせがネットワークセンターの名札を覆った → 画面に重ねた知らせと表示切替の範囲を測って名札の配置に渡し、そこを避ける
- 情報パネルを開くと UI が 20.2% になり V1 を割った → パネルの行の間を詰めて 19.5% に
- コンテナ施設の 2 分野で「まだ学習の記録が無い」が 2 回出て、パネルが長くなった → 理由が同じなら 1 度だけ書く
- 区画の建物を押した撮影が、手前の背の高い施設を選んでいた（選択の判定は正しい）→ 台本を、手前に何も無い建物を押すように直した
