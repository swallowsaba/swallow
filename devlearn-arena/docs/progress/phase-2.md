# Phase 2 都市・道路・建物

記録した日: 2026-10-02

## 実装したこと

- 配置の判定（`src/city/place.ts`）: 道路・区画・施設・公園を置けるかと、置けない理由
  （霧の中・海の上・丘の段差の上・建物や区画と重なる・道路と重なる・道路に面していない・入口が道路に面していない（R で回す）・資金が足りない・発展段階・橋）。置く・取り壊す関数も同じ所
- 道路（`src/city/roads.ts`）: 直線（縦か横にそろう）と、曲線（始点・制御点・終点の 2 次ベジェ）。大通り（2 マス）とロータリー（3×3）は地方都市から。
  川を渡る所は自動で「陸の道路・橋・陸の道路」に分けて橋を架ける（町から）。交差点は自動でつなぎ、行き止まりには転回場
- マスの単位の都市（`src/city/cells.ts`）: 地形の種類（陸・川・海・丘）、道路の通るマス（曲線でも上下左右につながる）、施設の入口のマス、使われているマス
- 成長（`src/city/growth.ts`）: 需要（住宅は雇用から、オフィスは技術力から、商業は人口から）で区画の建物が建つ。
  公園と施設の近くの建物は一段育つ（建て替えとして建設の 3 段階を通る）。村と町では 2 段（戸建て → 低層集合住宅）まで。
  都市規模・技術力から発展段階が上がり（`src/game/stage.ts`）、霧が晴れる（村 24×24 → 町 40×40 → …）
- 規則の値（`src/city/rules.ts`）と施設の定義（`content/facilities.json`、zod で検証）。資金は固定値 5,000 で、置いても減らない（この Phase の範囲）
- 建設の 3 段階の姿（`src/city/generate/construction.ts`）: 基礎（掘った地面・型枠・鉄筋・資材・黄の囲い・詰所）、骨組み（鉄骨の柱と梁・床・足場・大きな敷地はクレーン）
- 残り 12 施設と公園の類 4 種（公園・並木・広場・噴水）の Lv1 の自作 SVG（`src/city/generate/facilities/` の模型から `npm run svgs` で作る。全て 30KB 以内）
- 車と人（`src/city/traffic.ts`）: 道路の網（交差・丁字路）を seed からたどる道のり。車は左側の車線、人は縁石の上を歩く。数は都市規模と稼働中の施設で増える。
  車 5 色・人 4 種の自作 SVG。近くの建物と前後を比べ、描く順の正しい所に差し込む
- 描画: 区画の地面の色、橋（欄干・影・橋桁）、大通りの中央分離帯と並木、ロータリー、霧（外を白く霞ませ、境をぼかす）、配置の予告（緑と赤の枠・道路の形・施設の姿）
- 都市画面: 建設メニュー（下中央、高さ 72。道路・区画・施設・公園・取り壊し）と引き出し、カーソルの横の小窓（何を置くか・費用・理由）、
  取り壊しの確認の窓（施設を壊しても学習の記録は消えない）、上の帯の下の知らせ（町に発展した・一時停止中）。
  操作: 建設メニュー → 左クリック（道路と区画はドラッグ）/ R で回す / Esc と右クリックで取り消す / Space で一時停止 / B で建設メニュー
- 撮影の台本: `SHOOT_SCRIPT=tools/scenarios/town.mjs npm run shoot -- <名前>`（画面の操作だけで村から町を作る）、
  `tools/scenarios/avenue.mjs`（大通りとロータリー）、`tools/scenarios/menu.mjs`（引き出し）、`node tools/facility-sheet.mjs`（施設の SVG の一覧）
- 既存のコードの一覧（`docs/archive/inventory.md`）: `src/city3d/` `src/legacy/city/` `src/features/citymap/` `src/features/map/` `src/engines/city/` は、
  道すじから外れた旧作業画面 `src/features/park/` が import しているため、削除の時期を旧作業画面と同じに直した（three の依存も同時）

性能: 町の規模（建物と木 557・車と人 126）を毎フレーム描き直して、1920×1080 で 60.0fps（Playwright の Chromium）。

気づいて直したこと:

- 曲線の道路の通るマスが斜めにだけつながり、区画が面さなかった → 線の上を細かく歩き、斜めに移る所に間のマスを足す
- 建設中の建物を需要に数えず、住宅が建ちすぎた → 建設中の分を需要から先に引く
- 施設の引き出しに同じ形の項目が 15 並び、V7 に触れた → 施設を 3 つの棚（学びと基盤・Web と開発・クラウドと運用）に分け、1 度に 5 つまで（棚は `content/facilities.json` のデータ）
- 監視・運用センターの屋上が黄の板で覆われ、管制室の窓が見えなかった → 屋上の縁だけを分野の色にし、管制室の 4 面にガラスの帯
- コンテナ施設のクレーンの上が平らな板に見えた → 2 本の桁と横のつなぎにした
- 研究施設の窓が裏から見ると無かった → 全ての面に窓を付け、見えない面は描く時に省く
