# Phase 1 都市画面のプロトタイプ

記録した日: 2026-10-02

## 実装したこと

- `src/city/projection.ts` `camera.ts`: 等角投影（横 2 : 縦 1）、90 度単位の回転、カメラ（移動・拡大縮小・回転）の純粋な計算
- `src/city/terrain.ts`: 96×96 の地図に、浮いた島の地盤（土と岩の厚い縁）・海（深い所・浅瀬・波打ち際）・曲線の海岸線と砂浜・
  北の泉から南の海へ蛇行する川・3 段の丘 3 つ・畑・森と木を seed から作る
- `src/city/generate/`: 凸な部品（箱・切妻と寄棟の屋根・角柱・棒・扉・窓・看板・植え込み・街灯・木）を組み、
  面の向きで陰を付け（上 1.0・左 0.8・右 0.6）、奥から手前に並べる小さな 3D の模型。区画の建物（戸建て・低層集合住宅・店・事務所）を手続き的に生成
- `src/city/assets/facilities/`: 施設 3 種（市立 IT 学院・サーバ施設・ネットワークセンター）の Lv1 の自作 SVG。
  `tools/build-facility-svgs.mts`（`npm run svgs`）が模型から作る。1 つの SVG に正面と裏の姿を持ち、左右の映しと組み合わせて 4 つの向きで入口が正しい側に来る。各 30KB 以内
- `src/city/sample.ts`: 手で置いた見本の街（一般道 2 本・細い道 4 本（うち曲線 1 本）・区画の建物 77 軒・施設 3 種 Lv1）。交差点の横断歩道・中央線・行き止まりの転回場・街灯
- `src/city/render/`: 地面を拡大率と向きごとに 512 画素の区切りで画像化し、建物と木の絵を拡大率ごとに画像化して使い回す。見えない物は描かない
- `src/ui/tokens.ts`（色・文字の大きさ・フォント）、`src/ui/fonts.ts`（@fontsource で 4 フォントを同梱）、上の帯（`src/ui/TopBar.tsx`）、自作のアイコン
- 画面の切り替えをハッシュ（`#/city`）に替え、起動直後を都市画面にした。1280×720 未満では「PC の大きな画面で遊んでください」
- `npm run shoot -- <名前> <パス>`（`tools/shoot.mjs`）: 開発用のサーバを立て、1920×1080 で `shots/` に撮る。`SHOOT_FPS=1` で fps を測る
- 旧 `src/ui/` を `src/legacy/ui/` へ移した（新しい `src/ui/` の場所を空けるため。削除は旧画面と一緒）

気づいて直したこと:

- 島全体の撮影で、川が海の上まで続いていた → 川を陸の輪郭の中だけに描くようにした
- 丘の 1 つが海岸の外へはみ出していた → 丘を陸の中に置き直し、「丘は陸の中で海岸から離れている」をテストにした
- 回転すると施設の入口が道路と反対を向いた（SVG が 1 つの向きしか無かった） → 正面と裏の 2 つの姿を 1 つの SVG に持たせた
- 店の裏側が窓の無い箱に見えた → 裏の窓・裏口・室外機・ごみ置き場を足した
