# Phase 6 解説・理解・クイズ

記録した日: 2026-10-03

## 実装したこと

- `src/learning/lessonFlow.ts`（純粋な TS）: 7 段の順と名前・開ける段（進んだ段まで。終わった段は戻って見られる）。
  解説は 1 画面 1 問い（何か → なぜ必要か → 何に使うか → どんな場面で使うか → 状況説明。1 画面 200 字以内のため）。
  理解の 6 形式（図の一部を押す・順に並べる・状況説明・はい／いいえ・用語と説明を結ぶ・関係性）の判定と、間違えた時に示す解説の箇所。
  クイズの 7 形式（選択・複数選択・状況判断・原因特定・結果予測・用語理解・並べ替え）の判定（選んだ誤答・選び損ねた正答・位置の違う手順）。
  並べ替えの順と選択肢の順は seed（レッスンと問題の ID）から決める。開き直した時の段と、クイズのまだ正解していない問題
- `src/game/progress.ts`: `enterLesson`（学習中なら続きから）と `reachStage`（進んだ段を残し、見返しても戻さない）
- レッスン画面（`src/screens/lesson/`、`#/lesson/<ID>`）: 都市の施設の中に入る別の画面（`docs/decisions.md` D-07）
  - 背景にその分野の施設の中の景色を薄く敷く。上の帯に施設名・レッスン名・難易度・7 段の進み・この回の XP・「中断して都市へ」
  - 左に段の中身、右に図（左右の境はドラッグと矢印キーで動かせる）、下に推奨前提・関連・次に学ぶとよい（押すと入口の札）と「次へ」
  - 解説: 到達目標と、問いの頁。右に図。本文の用語は下線で、押すと小窓（簡単な説明・なぜ重要か・関連する技術。関連を押すと切り替わる・用語集で開く）
  - 理解: 採点しない（XP 無し）。間違えると「もう一度考えてみよう」と、関係する解説の箇所を出す。正しく答えると次へ。図の部分は Tab と Enter でも押せる
  - クイズ: 1 問ずつ「答える」。誤答には「なぜ違うか」、正答には「なぜ正しいか」とほかの選択肢がなぜ違うか、得た XP。コマンドと記録（ログ）は等幅で出す
  - 実戦の段: 目的と手順の目的を打つ前に示す。模擬環境につなぐのは Phase 7（それまでは「準備中」と出し、進みを保存して止まる）
  - Esc は用語の小窓を先に閉じ、それ以外は中断して都市へ。中身を書き起こしていないレッスンは「準備中」と出し、学習中として記録しない
  - 学習ライブラリの「このまま始める」と情報パネルの「ここで学ぶ」から、レッスン画面に入る。ブラウザの「戻る」で 1 つ前の画面へ
- 施設の中の景色 15 枚（`src/screens/lesson/backdrops/<施設>.svg`）: 都市と同じ描き方の模型（`src/city/generate/interiors.ts`）から `tools/build-facility-svgs.mts` で作る。
  奥の 2 面の壁（窓の外に街並み・幅木と分野の色の帯）と床に、施設ごとの設備と家具。`CREDITS.md` に記した
- 置き換えの済んだ旧コード（5 段の学び `src/lesson/`・旧図 `src/visual/`・旧作業画面と 3D の街・クリーム色の旧画面）と three.js を削除（`docs/archive/inventory.md` 7 章）
- 撮影の台本 `SHOOT_SCRIPT=tools/scenarios/lesson.mjs npm run shoot -- p6-end`、施設の中の景色の一覧 `node tools/backdrop-sheet.mjs p6-backdrops`

- クイズの判定と XP: 7 形式の判定。見本の 2 本の全問で、正答なら正解・どの誤答でも不正解。画面では誤答の理由・正答の理由・ほかの選択肢の理由。
  初回の正解 +5・誤答の後の正解 +2（`docs/game-design.md` 3 章）。得た XP と同じ量が都市の資金に入る（スキルの段階が上がった +50 も含む）。選択肢の順は同じ問題でいつも同じで、正答がいつも先頭ではない

- 途中保存と再開: クイズの途中で中断して開き直すと、クイズの段のまだ正解していない問題から。前に正解した問題は正解の形で見える。学習中のレッスンを開き直しても段は戻らない（`enterLesson`）
- 枠: 施設の中の景色（found.b.04 は市立 IT 学院・linux.i.01 はサーバ施設・k8s.b.01 はクラスタ施設）・施設名とレッスン名・下の帯のリンク・Esc と「中断して都市へ」・準備中のレッスンは記録しない

気づいて直したこと:

- クイズの正答がどの問題も選択肢の先頭（データで正答を先に書いているため）で、位置で当てられた → 先に「正答がいつも先頭ではない」テストを書いて再現し、選択肢を seed で決めた順に出すようにした
- 施設の中の景色で、壁に貼った物（開発オフィスの白板・クラウドセンターの画面・かんばん・金庫の扉）が、描く順で壁の裏に回って消えていた → 壁に貼る物を壁の部品の一部として描くようにした
- 一覧の撮影で、景色の色がおかしく見えた（1 枚の HTML に SVG を並べると、SVG ごとの class の名前がぶつかる）→ 一覧は 1 枚ずつ画像として置く道具（`tools/backdrop-sheet.mjs`）にした。画面では `<img>` で読むのでぶつからない
- 解説の短い頁で、左の窓の下半分が空いていた → 窓を中身の高さにし、到達目標を頁の上に出した（景色が広く見える）
- 1 問目の正解で XP が 55 増えたのを、テストを書いた時に XP の誤りと思ったが、IT 基礎のスキルが未修得から見習いへ上がった +50（`docs/game-design.md` 3 章）だった。
  上の帯の「この回の XP」はこのレッスンの XP だけを出し、スキルの段階の上がりは XP / スキルの段（Phase 7〜8）で見せる
