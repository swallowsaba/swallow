# Phase 5 学習コンテンツの構造

記録した日: 2026-10-03

## 実装したこと

- 旧コンテンツ（`src/content`）を `src/legacy/content` へ移し、新しい読み込みの場所を空けた
- `content/` の形と zod の検証（`src/content/schema.ts` `validate.ts`）。`npm run build` の最初にも検証が走り、失敗したらビルドで落ちる（`scripts/validate-content.mts`）
- 全レッスンの目録（`content/catalog.json`）: `docs/curriculum.md` の表から全 211 本の ID・題名・難易度・テーマ・到達目標・実戦の形・推奨前提・関連・次を書き起こした（`scripts/build-catalog.mts`。手で直さない）。
  推奨学習順は 2 章の分野の順 → 各表の行の順。`content/domains.json` は分野の一覧
- 用語集（`content/glossary/<分野>.json`、23 語）とエラーの解説（`content/errors/linux.json`）
- 最初のレッスン 2 本: `docs/lessons/found.md` の found.b.04（ファイルとディレクトリ）と `docs/lessons/linux.md` の linux.i.01（サービスと systemd）を、設計の要素を削らずに書き起こした。図 2 枚（`content/figures/`）
- `src/learning/`（純粋な TS）
  - `library.ts`: 学習ライブラリの並び（分野 → テーマ、推奨学習順）・検索（ID・題名・到達目標・テーマ・分野の名前。全角半角と空白は無視）・難易度と修了状況と分野の絞り込み・
    入口の札（到達目標・目安時間・難易度・推奨前提・関連・次。未修了の前提は「先に〇〇を見ておくと分かりやすい。このまま始めてもよい。」）。`canStart` は型の上でも常に true
  - `graph.ts`: 知識グラフの配置。分野は推奨前提の深さで左から右の列へ、全分野を束ねるトラブルシューティングと研究は右端の列。レッスンは分野の点の下に初級・中級・上級の 3 段。
    分野の名前は点の上（重なる時だけ段の下）。点と輪の大きさは縮める割合に合わせる
  - 情報パネルの「ここで学ぶ」: 施設の分野のレッスンを推奨学習順・未修了優先で 3 つ
- `src/game/progress.ts` の `enterLesson`: 画面からレッスンに入る時、学習中なら進んだ段から続ける（記録の再生の `startLesson` は新しい回のまま）
- 画面（`src/screens/learn/` `src/screens/glossary/` と、共通の窓 `src/ui/Window.tsx`）
  - 学習ライブラリ（上の帯の「学ぶ」 / L）: 都市の上に重ねる窓。左に分野の目次（修了の数）、中央に検索・絞り込みとレッスンの行、右に入口の札。
    札のボタンは「このまま始める」（学習中なら「続きから学ぶ」、修了なら「もう一度学ぶ」）と「先に〇〇を見る」だけで、禁止のボタンは無い。前提・関連・次を押すとその札へ移る
  - 知識グラフ（G）: 分野を大きな点、レッスンを小さな点で、分野どうしの推奨前提を矢印で描く。修了したレッスンは金色に光り、分野の輪が修了の割合だけ光る。
    レッスンを押すと入口の札、指したレッスンの推奨前提（入る辺）とそれを前提にするレッスン（出る辺）を描く。分野を押すとその分野の前提の辺を強める
  - 用語集（上の帯の「用語」）: 全用語の一覧と検索（言葉・読み・説明）。簡単な説明・なぜ重要か・例え・関連する用語・関係するレッスン（押すと入口の札）
  - 情報パネル: 「ここで学ぶ」の行を押すとそのレッスンを始め、「学習ライブラリで全部見る」は施設の分野で絞って開く
  - 上の帯: 今開いている画面の入口に印。Esc・「都市へ戻る」・都市名で都市へ。直リンク `#/learn/<ID>` `#/graph/<ID>` `#/learn?domain=<分野>` `#/glossary/<ID>` とブラウザの「戻る」
  - レッスンを始めると学習中として記録する（レッスンの各段の画面は Phase 6）
- 撮影の台本 `SHOOT_SCRIPT=tools/scenarios/library.mjs npm run shoot -- p5-end`: L で学習ライブラリ → 検索 → 入口の札 → 先に前提を見る → このまま始める → G で知識グラフ →
  2 週間ぶん学んだ後のグラフ → 分野を押す → 施設の情報パネルから学ぶ・全部見る → 用語集 → 用語からレッスン → 直リンク

気づいて直したこと:

- 1280×720 の知識グラフで、分野の修了の輪（大きさが固定の 20px）がレッスンの 1 段目の点に重なり、押したレッスンが分野に取られて札が開かなかった（撮影の台本が止まって分かった）
  → 先に重なりを確かめるテストを書いて再現し、点と輪の大きさを縮め方に合わせ、レッスンの段を少し下げた
- 用語集の一覧で、語が 1 文字ずつ縦に割れていた。分野の目次の配置（`grid-area`）を共通の菱形の部品に書いていたため、用語の行の中でも効いていた → 目次の中だけに効くようにした
- 知識グラフでレッスンを指した時の説明が、点の上の分野の名前を隠していた → 説明をその分野のレッスンの段の下に出すようにした
- 学習中のレッスンを開き直すと、進んだ段が解説に戻っていた → 先にテストで再現し、画面から入る時は続きから始めるようにした（`enterLesson`）
