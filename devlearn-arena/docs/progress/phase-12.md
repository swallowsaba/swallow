# Phase 12 UI/UX の改善

記録を始めた日: 2026-10-09（途中まで）。終えた日: 2026-10-16

10-09 に未決 U-11（ミニマップ）を書いて止まり、利用者の判断（案 A。`docs/decisions.md` D-18）の後、実戦の作り直し（`docs/progress/rework-practice.md`）を先に済ませてから続けた。

## 実装したこと（コミットの順）

- 12-0 片付け: 起動から辿れない旧来のコードと依存を消した
- 12-1 設定の項目: 音・動きを減らす・文字の大きさ・表示品質・ふりがな・コマンドの候補（設定画面の「遊び方」。選ぶとすぐ効き、自動で保存する）
- 12-2 初回の操作説明: 都市の作り方・施設で学ぶ・学ぶと都市が育つ、を示す所を囲んで 3 回に分けて説明する（Enter で次へ、Esc か「飛ばす」で飛ばせる）
- 12-3 キーボード操作と明るさの差の自動検査
  - `e2e/keyboard.spec.ts`: マウスを使わずに、操作説明 → 移動・拡大・回転 → Tab で施設 → Enter で情報パネルの中 → レッスン → Enter と Backspace で段 → Esc で都市 → L・G・Space・B
  - `src/ui/contrast.test.ts`: 画面の CSS で文字に使う色を全て拾い、HUD の地（下の都市の明るい所・暗い所に重ねた色）で 4.5:1 以上を確かめる。赤（3.26:1）は文字に使わず、印（アイコン・縁・線）にだけ使うようにした
- 12-4 読み込み中の演出（`src/ui/boot.ts`）: 本体が届く前から、地面 → 道路 → 建物 → 窓と木、の順に輪郭を描き、1.8 秒で描き終える。都市が描けたら 0.3 秒で消える
- 12-5 性能: 名札の配置の判定を軽くした（町の規模で 53.5fps → 58.6fps、1920×1080）。レッスン・ミッションの実戦の画面が都市を覆っている間は都市を描かない
- 12-6 オフライン（`src/offline/`）: 自作の Service Worker。一度開いた後は、回線が無くても都市と読んだレッスンが開ける。読んでいないレッスンは案内を出し、「もう一度読む」でページを開き直す。検討の結果は `docs/architecture.md` 4 章
- 12-7 ミニマップ（D-18）: 都市画面の左下に、島の形（海・陸・川・丘）・区画・道路・施設の点（分野の色。建設中は沈めた色）・晴れていない所の霞・今の視野の枠を描く。押した所（押したまま引きずればその先）へカメラが動き、都市の回転に合わせて回る。
  大きさは 160×160、画面の高さが 900 未満では 100×100。おすすめの欄の高さの上限を、900 未満では 120 に下げた。設定の「ミニマップ」で消せる（設定と保存データの版 3 は 10-09 に作ってあった）
  - 座標（`src/city/minimap.ts`）は模型の層、描き方（`src/city/render/minimap.ts`）は描画の層、部品は `src/screens/city/Minimap.tsx`。下絵は都市の形（道路・区画・施設・晴れた範囲）か向きが変わった時だけ描き直し、視野の枠はカメラが動いた時だけ重ね直す
- 12-8 気づいていた不具合: レッスンの中身が無い間（準備中・読み込み中・読めなかった時）に、右の窓の位置に中身の無い細い枠が出ていた。右の窓と左右の境を出さないようにした（先に失敗するテストを書いた）
- 12-9 撮り直しで見つけた崩れ（1280×720）
  - 設定の窓: ミニマップの行が増え、右の列の「最初からやり直す」が窓の下端に掛かっていた。画面の高さが 800 未満では、行と区画の上下の余白を詰めた
  - 学習ライブラリの分野の目次: 幅 1600 未満で目次が 196 に狭まり、「トラブルシューティング」の修了の数（0/9）が押し出されていた。目次の幅を 232 に揃え、長い名前は省略の印で切るようにした
- 撮影の道具: `SHOOT_DPR`（画素の倍率。ミニマップのような小さい部品を細かく撮る）を足した。`tools/scenarios/inspect.mjs` の常時の UI の割合に、ミニマップを数えるようにした

## 計測

- 都市画面の fps（Playwright の Chromium、毎フレーム描き直し、`tools/scenarios/inspect.mjs` の町）: 1920×1080 で 56.7fps（描いた物 389）、1280×720 で 60.2fps（描いた物 295）。12-6 の時点は 1920×1080 の町（描いた物 551）で 58.6fps
- 常時の UI の割合（`tools/scenarios/inspect.mjs`。おすすめの欄とミニマップも数える）: 1920×1080 で 11.6%、1280×720 で 19.6%（ミニマップを足す前は 9.6% と 19.8%。900 未満でおすすめの欄の上限を下げた分だけ、1280×720 は減った）

## 視覚確認

撮影: `.tmp-shootall.sh`（手元の一時の台本。全ての撮影の台本を順に動かす）で `shots/p12-1920x1080/` と `shots/p12-1280x720/` に 127 枚ずつ撮り直した。直した後の設定・学習ライブラリは 1280×720 で撮り直し、1280×720 未満の案内は `SHOOT_SIZE=1100x700` で撮った（`p12-small-1100.png`）。ミニマップは `SHOOT_DPR=2` で拡大して撮った（`mm-1` 回す前・`mm-rot` 回して引いた後・`mm-click-full` 押した後）。

開いて確かめた画面（両方の大きさ）: 都市（見本・町・選んだ所・表示切替 4 種・建設の引き出し・施設のレベル・学習の後の知らせ）・初回の操作説明 3 回・読み込み中の演出・学習ライブラリ・知識グラフ・用語集・成長・ミッションの一覧と実戦・レッスンの 7 段（解説・理解・クイズの誤り・実戦の端末・設定の編集・SQL・画面の操作・エラー・結果・まとめ・XP）・読めなかった時・設定（標準と特大の文字）・保存（読み込む前の中身・やり直しの確かめ）。
