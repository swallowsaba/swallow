# Phase 11 セーブ・データ管理

記録した日: 2026-10-09

## 実装したこと

自動保存・起動時の読み込み・保存の失敗時の案内・版と移行の仕組みは、至急 01（`docs/progress/urgent-01.md`）で先に作った。この Phase では残りを作った。

- **書き出し・読み込み・最初からやり直す**（`src/save/manage.ts`）
  - 書き出し: 今の状態の保存データを `devlearn-save-<日付>.json` にする
  - 読み込み: zod で形を確かめ、版を移す（`readSave`）。読めた時は中身（都市と市長・保存した時・XP・修了したレッスンの数・古い版から移したか）を返す。読めない時は、何が起きたか・どうすればよいかを 1 行ずつ返す（投げない）
  - やり直し: 新しい都市・空の学習の記録・新しい市長の保存データ。設定は今のまま残す
- **置き換え**（`src/save/autosave.ts` の `replace`）: 待っている保存を書き終えてから、置き換える保存データを書く。書けたら見張りを止め、以後は元の画面の状態で上書きしない（ページを離れる時の書き切りでも）。
  書けなければ投げ、今の記録のまま自動保存を続ける。`snapshot` で今の状態の保存データを取れる（書き出しに使う）
- **設定画面**（`src/screens/settings/SettingsScreen.tsx`。上の帯の「設定」、`#/settings`）: 都市の上に重ねる計器の窓。「保存」の欄に、自動保存の様子（問題があればその 1 行）と、書き出す・読み込む・最初からやり直すの 3 つの区画を横に並べた
  - 読み込む: 「ファイルを選ぶ」→ 中身を示す → 「置き換える」/「やめる」。読めないファイルは赤い縁の 2 行（何が起きたか・どうすればよいか）
  - 最初からやり直す: 押すと、消える物と残る物を示して確かめる。「やめる」「先に書き出す」「やり直す」
  - 置き換えた後は保存先から開き直し（`src/main.tsx`）、都市画面から始めて 1 行で知らせる（「保存データを読み込んだ（みなと市・2026-10-09 07:03 に保存した記録）。」「最初からやり直した。新しい都市で始める。」）
- アイコン 4 つ（書き出す・読み込む・やり直す・保存）を `src/ui/icons/Icon.tsx` に足した
- `docs/data-model.md` 7 章に、読み込みとやり直しの確かめ方・設定を残すこと・置き換えた後の開き直しを書き足した
- 撮影の台本 `tools/scenarios/saves.mjs`
