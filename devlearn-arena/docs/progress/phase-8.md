# Phase 8 学習と都市成長の接続

記録した日: 2026-10-04

## 実装したこと

- 学習の結果 → XP・スキル・資金 → 都市
  - 学習で得た XP と同じ量の開発資金が都市に入る（Phase 4・7 で作った流れ）。学習に出る時の都市とスキルを覚え、戻った時に比べる（`src/city/changes.ts`）
  - 変化は大事な順に: 施設を次の Lv に上げられるようになった → 発展段階 → 区画に建った建物 → 育った建物 → 学んだ分野の施設がまだ無い
  - **施設のアップグレード**（`src/city/upgrade.ts`）: レベル N に上げるには、その分野のスキル段階 N 以上と資金（建てた費用 × N ÷ 2）。
    2 つの分野の施設（コンテナ施設）は高い方の段階で判定。建設中は上げられない。上げると技術力（施設の Lv の合計）が増え、発展段階の判定に入る
  - **大型施設**（`docs/decisions.md` D-12。未決 U-05 の判断 案 A）: 敷地が 3×3 の 5 施設（市立 IT 学院・研究施設・コンテナ施設・クラスタ施設・クラウドセンター）。
    Lv3 は地方都市・Lv4 は中核都市・Lv5 は技術都市から。ほかの施設は発展段階の条件なし。`docs/game-design.md` 5・6 章に書き足した。
    発展段階が届かない時は、戻った時に「上げられるようになった」とは言わない
  - 区画の成長と発展段階は、都市の時計の計算（`src/city/growth.ts`）がそのまま反映する
- 都市へ戻った時: いちばん大事な変化の場所へカメラが寄り（施設ならそれを選んで情報パネルを開く）、足元に広がる金の輪（6 秒）、
  上の帯の下に 1 行の知らせを順に（変化 → 学習で得た開発資金 → 次のおすすめ。1 つ 3 秒）
- 情報パネルのアップグレード: 条件を満たせば「LvN に上げる」。満たさなければ、まだ満たしていない物（スキルの段階・都市の発展段階・あと何の資金・建設中）を 1 行ずつ。
  押すと Lv が上がり、資金が減り、その場所を光の輪で示し、「〇〇を Lv2 に上げた。図書館棟が加わった」とすぐ知らせる
- おすすめの欄（左上・幅 300・高さ 160 まで・畳める。`src/learning/recommend.ts`）: 学習中 → 誤答の多い分野の推奨前提 → 最近修了したレッスンの次 → 推奨学習順。
  最初に遊ぶ人には IT 基礎の最初。復習の予定。押すとそのレッスンを始める
- ゲームループの E2E（`e2e/loop.spec.ts`）。旧画面の E2E（`e2e/smoke.spec.ts`）は `docs/archive/inventory.md` の判定どおり置き換えて削除した
- 撮影の台本 `SHOOT_SCRIPT=tools/scenarios/loop.mjs npm run shoot -- p8-end`（学習前 → 学習 → 戻った後 → 知らせ → 施設を上げる）

## テスト

- `npm run typecheck` `npm run lint` `npm run test`: 全て通過（135 ファイル・5,067 件）。`npm run e2e`（build → preview でサブディレクトリ `/devlearn-arena/` から配信）も通過
- 統合テスト（`src/__tests__/loop.test.ts`）: 見本の 2 本の学習記録 → 資金が得た XP と同じだけ増える → 戻ると 2 つの施設が Lv2 に上げられるようになる → サーバ施設を上げると技術力 2 → 3、資金 −400 → 市立 IT 学院は資金が足りない（あと何か）と出る。学ばずに戻ると何も上げられない
- アップグレードの規則（`src/city/upgrade.test.ts`）: 大型施設は 3×3 の 5 施設だけ。スキル段階と資金の条件。大型施設の Lv3〜Lv5 と発展段階。大型でない施設は村のままで Lv5 まで。2 分野の施設。建設中と公園の類
- 変化（`changes.test.ts`）: 大型施設の Lv3 は地方都市になるまで「上げられる」と言わない
- 都市の状態（`cityStore.test.ts`）: 上げると Lv・資金・光の輪・知らせ。足りなければ何も変えない。戻った時の知らせが並んでいても、上げた知らせはすぐ出す
- 情報パネル（`InfoPanel.test.tsx`）: 足りなければボタンを出さず理由を書く。満たせば「Lv2 に上げる」を押すと上げる操作を呼ぶ。大型施設の Lv3 の発展段階の条件
- 施設の絵（`sprites.test.ts`）: そのレベルの SVG が無ければ下のレベルの絵を、読み込み済みの名前で引く

## 視覚確認

撮影: `shots/p8-before.png`（学習前の都市）・`p8-after.png`（戻った直後）・`p8-after-notice.png`（次の知らせ）・`p8-panel.png`（情報パネル）・`p8-upgraded.png`（上げた後）と、同じものを 1280×720 で（`*-1280.png`）。全て開いて確かめた。

学習前と後を並べた変化: 開発資金 445 → 605、XP 0 → 160、都市規模 16 → 128 人。区画の建物は骨組みから完成した住宅と低層集合住宅に。
カメラは市立 IT 学院へ寄り、足元に金の輪、名札が金に、右に情報パネル、上に「市立 IT 学院を Lv2 に上げられるようになった（IT 基礎 初級）」。
上げた後は名札が「Lv2」、パネルが「Lv2」と次の Lv3 の条件（中級・地方都市・資金）に変わる。

| # | 結果 | 確かめたこと |
|---|---|---|
| V1 | 合格 | 学習前も戻った後も、都市ビューが画面の大部分。情報パネルは建物を選んだ時だけ右に出て、都市を覆わない |
| V9 | 合格 | 常時の UI（上の帯・おすすめの欄・建設メニュー・表示切替）を測ると、1920×1080 で 9.2%、1280×720 で 17.4%（20% 以内） |

気づいて直したこと:

- 上げた施設が消えて、敷地の金の枠だけが残っていた（`p8-upgraded.png` で気づいた）→ 絵を施設の Lv の名前（academy:2）で引いていたが、読み込んであるのは実際の SVG の名前（academy:1）だった。
  先に失敗する単体テストと E2E（上げた後に描いた物の数が減らない）を書き、実際に使う SVG の名前で引くように直した
- 上げた知らせが、戻った時の知らせ 3 つの後ろに並んで数秒遅れて出ていた（E2E で気づいた）→ 自分の操作の結果はすぐ出し、並んでいた知らせはその後に出す
- 情報パネルのアップグレードで、同じ条件が 3 度（名前の下・「条件:」の行・満たしていない理由）出ていた → 名前の下の条件と、満たしていない物だけにした
- 撮影の村では資金が 95 足りず、上げる所を撮れなかった → 台本の区画を 1 列にした（仕様どおり「足りない（あと 95）」と出ることは `p8-panel` の前の撮影で確かめた）
