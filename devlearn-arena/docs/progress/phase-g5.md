## 満たせなかった物・気づいた事

- **G5 の仮の決まりでは、住宅に接するデータセンターは、スキル 0 でもスキルがあっても通らない。** 公開 URL の町（人口 157）で、住宅の隣のデータセンターは公聴会の段で反対率 90%。
  電力に先回りの譲歩・冷却水に譲歩・雇用を押し切っても 89%、学んだ後に確かな説明と誤った説明を出しても 93% で、仮の決まり（50% 未満）で否決された。
  理由は 2 つ。(1) 押し切るは反対率を下げない（17.3）。仮の決まりは反対率だけで決めるので、政治資本の道は G6 の議会（押し切った論点を議員が 3 割に軽く見る・説得 +4）で初めて効く。
  (2) 雇用が少ないの強さ（1 − 敷地 1 マスの雇用 ÷ 都市の平均）が 0.9 前後で、若者と中年の世帯の懸念がこの理由だけで 1 に届く（`min(1, Σ)`）。ほかの理由に譲歩しても懸念が下がらず、雇用の割合が増えるだけになる。
  一方、同じ町の住宅の向かいの工業の区画（用途地域の変更）は、スキル 0 の譲歩で 8% の同意の案件になり完成した。`hearing.test.ts` の町（人口の多い村）では、住宅のそばのデータセンターも requires の無い譲歩だけで 45% → 35% になり可決する。
  学習のロックではない（スキルがあっても同じ。離した所に置けば 16% で通る）ので、仕様は変えずに G6 で、議会の採決の上でスキル 0 の譲歩と政治資本の道が残るかを確かめる（S3 は G7 の完成条件）
- 公聴会の窓を開いて毎フレーム描き直させた時の fps は 36（1920）。ぼかしの窓を 3 枚重ねるため。30fps 以上で、窓を開いている間は時間が止まるので、このままにする
