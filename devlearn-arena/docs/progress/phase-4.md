# Phase 4 プレイヤー・XP・スキル

記録した日: 2026-10-02

## 実装したこと

- 未決 U-01〜U-04 の判断（`docs/decisions.md` D-08〜D-11）を仕様書に書き、初めの資金を 1,500 にした。建てると資金が減る（足りなければ置けない理由が出る）
- `src/game/`（純粋な TS。React・DOM・`Date` を使わず、時刻は引数で渡す）
  - `xp.ts`: docs/game-design.md 3 章の表と稼ぎ防止（2 回目以降はまとめ 0・クイズと実戦 1/4・3 回以上の誤答の後の正解は 0）。端数は行動ごとに四捨五入（D-10）
  - `progress.ts`: 学習の行動（レッスンを始める・クイズに答える・実戦を終える・まとめまで到達・復習・ミッション）から記録・XP・資金・スキルの段階の上がり（+50）を計算する。
    1 日（端末の日付）に同じレッスンから得る XP は 1 回分まで。初めての修了で復習カードを作り、間隔は 1 → 3 → 7 → 14 → 30 日
  - `skill.ts`: 4 章の式（修了率 40・クイズの初回正答率 25（直近 20 問）・実戦の成功率 25（直近 10 回）・定着度 10）。四捨五入した整数で段階を決める。復習カードが無ければ定着度 0（D-11）。
    「何をしたからこの値か」の数（修了した本数・正解した問題・成功した実戦・予定どおりの復習カード）も返す
  - `rank.ts`: エンジニア段階（見習い 0 / ジュニア 1,000 / ミドル 5,000 / シニア 12,000 / リード 20,000。D-08）
  - `stage.ts`: 発展段階（技術力と都市規模の両方）と、段階で新しくできること
  - `records.ts`: 模擬の学習記録（レッスンの回・復習・ミッション）をまとめて与える。レッスンの画面ができるまでの入口
  - `lessons.ts` と `content/lesson-list.json`: docs/curriculum.md の全 211 レッスンの ID と題名（修了率の分母と学習履歴に使う。Phase 5 で目録に置き換える）
- 画面の層（`src/screens/`）: 都市と学習の記録を 1 つの `Session` に持ち、学習で得た XP と同じ量を都市の資金に入れる。端末の時計は画面の層だけが読む（`clock.ts`）
- 上の帯: XP の欄にエンジニア段階を添え、押すと成長画面（`#/growth`。直リンクでも開く）
- 情報パネル: 対応する分野のスキルの値・段階・「何をしたからこの値か」を学習の記録から出す
- 成長画面（`src/screens/growth/`）: 都市の上に重ねる 1 枚の窓。左にエンジニア段階の梯子（次まであと何 XP）と都市の発展段階の計器（技術力・都市規模、次の段階でできること）、
  中央に 16 分野のスキルの計器（段階の境目の目盛り付き）と、選んだ分野の内訳（4 つの項の点数と、何をしたからか。予定日を過ぎた復習があれば知らせ）、右に学習履歴（日ごと、いつ・何を・どれだけ理解したか）。
  Esc・「都市へ戻る」・上の帯の都市名で都市へ戻る。開いている間は都市のキーボードの操作を止め、都市の操作の部品を隠す
- 撮影の台本 `SHOOT_SCRIPT=tools/scenarios/growth.mjs npm run shoot -- p4-end`: 記録が無い状態 → 2 週間ぶんの模擬の学習記録（誤答・ヒント・エラーからの回復・復習のさぼりを含む）→ 上の帯 → 成長画面 → 分野の内訳 → 直リンクと都市名で戻る。
  町を作る台本（`town.mjs`）は、初めの資金が 1,500 になったため、先に模擬の学習記録で資金を得てから建てる

## 視覚確認

撮影: `shots/p4-start.png`（記録が無い都市）・`p4-growth-empty.png`（記録が無い成長画面）・`p4-topbar.png`（学んだ後の上の帯）・`p4-growth.png`・`p4-growth-linux.png`（成長画面と Linux の内訳）・
`p4-end.png`（都市名で戻った後）と、同じものを 1280×720 で（`*-1280.png`）。全て開いて確かめた。

| # | 結果 | 確かめたこと |
|---|---|---|
| V2 | 合格 | 成長画面は都市の上に浮かぶ暗色の窓（非対称の角・金の縁）。スキルは目盛り付きの計器の帯、エンジニア段階は梯子、数字は Barlow Condensed で桁を揃えた。ウェブページの部品に見えない。後ろに都市が見えている（窓は画面の 72.9%、1280×720 で 79.9%） |
| V7 | 合格 | 札を並べていない。スキルは 1 本の計器の表（行）で、内訳は選んだ 1 分野だけを 1 枚で出す。学習履歴は日ごとの行の並び（時刻・印・題名・XP）で、同じ形の札は無い |

気づいて直したこと:

- 1280×720 では中央の列の内訳が下に切れ、スクロールしないと「何をしたからこの値か」が見えなかった → 縦の低い画面では、スキルの計器を 2 列に、内訳の 4 項を 2×2 に詰めて、窓の中に収めた
- 学習履歴の「スキル」の行が「Linux / CLIの段階が」と英語と日本語の間が詰まっていた → 空白を入れた（テストで固定）
- 同じ日に同じレッスンを 2 回通した時、履歴の時刻がまとめの時刻ではなく実戦の時刻になっていた → 先にテストで再現してから、まとめの時刻を使うように直した
