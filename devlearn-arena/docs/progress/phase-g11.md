## テスト

- `npm run typecheck`・`npm run lint`・`npm run test`（214 ファイル・2,400 本）・`npm run content:check`・`npm run secrets` が通る
- 始め方: 表の係数・境・初めの政治資本・新しい都市はふつう・選ぶ命令で始め方と政治資本が変わり、都市と予算は変わらない・始めた後は選べない（`startMode.test.ts`）。窓: 3 つの数・既定・時間が止まる・操作説明は後・選んで始める・選ばずに閉じる・公約の窓は後・始めた後の都市では開かない（`StartWindow.test.tsx`）。初回の判定（`autosave.test.ts`）
- 褒賞: 節目の判定（下がっても残る）・効き・各 1 つまで・申請と費用（`rewards.test.ts`）。一覧と棚（`CivicWindows.test.tsx`・`BuildMenu.test.tsx`）。学習にロックが無い（褒賞はレッスンに関係しない。一覧の文と、`rewards.test.ts`）
- E2E: 初回の始め方の窓（`loop.spec.ts`）・最初からやり直した後に出て、穏やかな町で政治資本 14（`saves.spec.ts`）・落選の後の新しい都市で出て、手ごわい町で政治資本 7、公約の窓はその後（`election.spec.ts`）。手元で 40 本のうち 39 本が合格。`flow.spec.ts` の「7 段の途中で中断し、リロードしてから開き直す」は、ほかの物と同じ組で流すと落ちることがある。G11 の前のコミット（18979c8）でも同じに落ちる（3 回中 3 回）ので、この Phase の変更によらない。G12 の通しの確認で直す
- 性能（`npm run bench:sim`）: 1 日 平均 0.423ms・1 週 平均 41.3ms・最大 53.0ms・週の終わりの日 最大 58.5ms。目安以内
