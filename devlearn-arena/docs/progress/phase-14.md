## 実装したこと（コミットの順）

- 14-1 公開前の確認と、公開 URL へのテストの用意
  - `e2e/assets.spec.ts`: 全ての画面（都市・学習ライブラリ・知識グラフ・入口の札・用語集・成長・ミッション一覧と実戦・設定）と、分野ごとの最初のレッスン 15 本を開き、読み込みの失敗（400 以上・届かない物）・ページの誤り・コンソールの誤りが無いこと、施設の中の景色 14 枚が描けることを確かめる（`docs/deployment.md` 8 章「コンソールに 404 が無い」）。
    Service Worker が手元に持った物を返すと配信の失敗が見えないので、この E2E では Service Worker を止める。景色を 1 枚 404 にすると落ちることを確かめた（止める前は、404 にしても通ってしまっていた）
  - `E2E_URL=<公開 URL> npx playwright test` で、手元のサーバを立てずに公開 URL に対して E2E を動かす。`SHOOT_URL=<公開 URL>` で公開 URL を撮る（`docs/deployment.md` 7 章に書いた）
- 14-2 公開: main に push し、`ci.yml` と `deploy.yml` が通った（コミット `0eb8864`）
- 14-3 撮影の台本 3 つ（読み込みの演出・レッスンの前半・読めなかった時）が、開発用のサーバにしか無い物（`/src/main.tsx`・`/content/…json`）を使っていて、公開 URL では撮れなかった。build した物の名前（`assets/index-*.js`・`assets/net.*.js`）も扱い、答えは手元のファイルから読むようにした。アプリの不具合ではない
