# ビジュアルデザイン

画面の構成は `docs/ui-design.md`、都市の構造は `docs/city-design.md`、素材の権利は `docs/asset-policy.md`。
この文書は**見た目の決まり**（字・色・質感・建物の描き方・禁止事項・視覚確認）を決める。

## 1. ビジュアルコンセプト

**「育ちつつある技術都市を、管制室から見下ろす」**

- 主役は都市。明るく生きた色の都市と、その上に浮かぶ落ち着いた暗色の半透明な操作盤（HUD）
- HUD は「PC ゲームの計器」。ウェブページの部品に見せない
- 光は意味のある所だけ（稼働・選択・変化）。飾りで光らせない

## 2. フォント

**ブラウザの標準フォントをそのまま使わない。** 全て SIL Open Font License の自由に使えるフォントを、npm（@fontsource）で**同梱して配信**する（外部のフォント配信に依存しない）。

| 用途 | フォント | ウェイト | 代わり（読み込めない時だけ） |
|---|---|---|---|
| 見出し（画面名・施設名・段の名前） | M PLUS 1 | 700 / 800 | "Noto Sans JP", "Hiragino Sans", "Yu Gothic UI", sans-serif |
| 本文（解説・説明） | Noto Sans JP | 400 / 500 / 700 | "Hiragino Sans", "Yu Gothic UI", "Meiryo", sans-serif |
| UI（ボタン・ラベル・メニュー） | Noto Sans JP | 500 / 700 | 同上 |

## 4. 質感と形

- HUD の窓: 角を非対称に丸める（左上と右下 4px、右上と左下 18px）。縁 2px（`hud.line`）。影 `0 10px 26px rgba(0,0,0,.45)`
- 主要な操作のボタン: 斜めに切った形（`clip-path` の平行四辺形）。押すと 2px 沈む
- 選択中: 金の地に紺の文字、横に小さく揺れるカーソル
- 文字の背後に模様を敷かない。読みやすさを優先する
- アイコンは自作 SVG（線 1.6〜2px、角は丸く）。絵文字は使わない

## 5. 建物の描き方（SVG）

`docs/city-design.md` 7 章の規則を、SVG で次のように実現する。

- 1 つの建物 = 1 つの SVG。原点は接地の中心。等角投影（横 2 : 縦 1）の座標で描く
- 面は 3 色（上面 1.0〜1.1 倍・左面 0.8 倍・右面 0.6 倍の明るさ）
- 窓は面の傾きに沿った平行四辺形。反射の色と、稼働を示す灯りの色を混ぜる（灯りは全てではなく 30〜50%）
- 細部を 3 つ以上（庇・看板・屋上設備・手すり・配管・アンテナなど）
- 接地の影（右下へ伸びる半透明の多角形）
- 施設は Lv1〜Lv5 の 5 枚。Lv が上がるほど棟・高さ・細部が増える
- 区画の建物は、同じ規則の手続き的な生成で描いてよい（`src/city/generate/`）
- 1 つの SVG は 30KB 以内（読み込みを軽く）

## 6. 図（レッスンの図）

- SVG。HUD と同じ色と字
- 1 枚の図に要素 7 つまで。矢印は流れの向きを示す時だけ
- 図の中の文字は 13px 以上
- 状況説明の図で街や建物を描く場合は、都市と同じ 2.5D の描き方

## 6.1 アセット

素材の権利は `docs/asset-policy.md`。ここでは**どんな素材を、どこに、どの形で持つか**を決める。

| 種類 | 形式 | 置き場所 | 数と決まり |
|---|---|---|---|
| 施設 | 自作 SVG | `src/city/assets/facilities/<施設>/lv<1-5>.svg` | 15 施設 × 5 レベル。`docs/city-design.md` 4 章 |
| 区画の建物 | 手続き的な生成（同じ描き方の規則） | `src/city/generate/` | 住宅・商業・オフィス × 段階 |
| 道路・橋・ロータリー | 手続き的な描画 | `src/city/render/` | `docs/city-design.md` 2 章 |
| 木・街灯・ベンチ・噴水・記念碑 | 自作 SVG | `src/city/assets/props/` | 各 3 種以上の変化 |
| 車・人 | 自作 SVG | `src/city/assets/agents/` | 車 5 色・人 4 種。人は小さな影絵で顔を描かない |
| 施設の中の景色（レッスン画面の背景） | 自作 SVG | `src/screens/lesson/backdrops/<施設>.svg` | 15 枚 |
| アイコン | 自作 SVG | `src/ui/icons/` | 線 1.6〜2px。絵文字を使わない |
| レッスンの図 | 自作 SVG | `content/figures/<ID>.svg` | 6 章の決まり |
| フォント | woff2（@fontsource） | 依存として取得 | 2 章 |
| 効果音 | 自作（Web Audio で波形から作る。音声ファイルを持たない） | `src/lib/sfx.ts` | `docs/decisions.md` Q-03。設定の「音」を入れた時だけ鳴らす |

- ファイル名は小文字の英数字とハイフン
- 各 SVG は 30KB 以内。`viewBox` を必ず持ち、色は tokens の値だけを使う
- 新しい素材を足したら `CREDITS.md` を同じコミットで更新する

## 7. 禁止事項

- ブラウザ標準フォントのまま / 指定以外のフォント
- 四角＋三角の家 / CSS の図形で作った建物 / 絵文字の建物やアイコン
- 単純なプレースホルダー（灰色の箱・仮の円）を完成版として残す
- 古いウェブサイト風・管理画面風・Bootstrap そのまま・青いリンクの羅列
- カードの羅列 / 四角いボタンの羅列 / スマホゲーム風の大きな丸ボタンと派手な演出
- 白い背景に黒い文字だけの学習ページ（学習サイトに見える）
- Cities: Skylines II の UI・画像・建物・アイコン・色の組み合わせを写す
- 飾りの光（意味の無い発光・点滅）

## 8. 視覚確認の項目

各 Phase の終わりに、撮影した画面で**全て**確かめる（`docs/testing-strategy.md`）。

| # | 項目 | 合格の目安 |
|---|---|---|
| V1 | 都市が主役か | 都市画面で、都市ビューが画面の 80% 以上見えている |
| V2 | PC ゲームらしいか | 横長の画面を活かし、計器のような HUD。ウェブページの見た目でない |
| V3 | 疑似 3D として成立しているか | 建物に奥行き・側面・屋根・影がある。平面の四角に見えない |
| V4 | 建物が単純図形になっていないか | 窓・入口・細部 3 つ以上・周辺環境がある |
| V5 | 古いウェブサイトに見えないか | 標準のボタン・青いリンク・枠線だけの表が無い |
| V6 | 標準フォントになっていないか | 指定のフォントで表示されている（撮影で確認） |
| V7 | カードだらけになっていないか | 同じ形の札が 6 枚以上並ぶ画面が無い（学習ライブラリの一覧を除く） |
| V8 | 学習サイトに見えすぎないか | レッスン画面に施設の景色があり、都市の中で学んでいる体裁になっている |
| V9 | 都市が UI に埋もれていないか | 常時の UI が画面の 20% 以内 |
| V10 | 名札が重なっていないか | 名札どうし・名札と建物が重ならない |
| V11 | 絵文字が無いか | 画面とコードに絵文字が無い |
