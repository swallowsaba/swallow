# レッスン設計

`docs/curriculum.md` の全レッスンを、指示書 20 節のとおり **解説 → 理解確認 → クイズ → 実戦 → 結果 → まとめ** まで設計したもの。
分野ごとに 1 ファイル。コンテンツ（`content/lessons/`）は、この設計を `docs/content-spec.md` の形に書き起こして作る。

## 書式（全分野共通）

```text
### <ID> <題名>（<テーマ>・<難易度>）
- 解説: 何か ｜ なぜ必要か ｜ 何に使うか ｜ どんな場面で使うか
- 状況説明: （任意）その技術が必要になる実際の場面
- 図: 解説に付ける図の中身
- 理解: 2 つ以上（[図] [状況説明] [はい・いいえ] [用語] [関係性] [並べ替え]）
- クイズ: 3 問以上・3 種類以上（[選択] [状況判断] [原因特定] [結果予測] [用語] [並べ替え]）。→ の後が正答
- 実戦（端=仮想端末 / 模=模擬環境 / S=ブラウザ内 SQL / 編=設定の編集）:
  目的 ／ 初期状態 ／ 達成条件（模擬環境の状態で判定）／ ヒント①方向 ②具体 ③そのまま通る答え ／ 想定エラー → 原因候補
- 結果: 成功時 ／ 未達時
- まとめ: 要点 3 つ ／ 次に学ぶとよい
```
