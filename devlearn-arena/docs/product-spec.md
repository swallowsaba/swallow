# プロダクト仕様

## 1. 目的

**IT エンジニアとして成長すると都市が成長する、PC 向け都市開発シミュレーションゲーム**を作る。
学習者は、都市を育てたい・次の施設を作りたい・新しい技術を知りたい、という動機で学び続け、
実際のエンジニアが持つ「理解する → 操作する → 結果を見る → 問題を見つける → 原因を調べる → 直す → 確かめる」力を身に付ける。

作らないもの: IT 学習サイトをゲーム風に飾ったもの。

都市を作る仕組みの参考元は Permit Pending（`docs/decisions.md` D-20）。採るのは仕組みの構造（模擬・許認可・反対・公聴会・議会・選挙）だけで、見た目・名前・住宅危機という主題は持ち込まない。

## 2. 対象者

- 主: IT 未経験〜初級のエンジニア志望者、新人エンジニア（中学生以上が読める日本語）
- 副: 特定分野（Kubernetes・ネットワークなど）を補強したい現役エンジニア
- 利用環境: PC のブラウザ（横長の画面、マウスとキーボード）。1280×720 以上。推奨 1920×1080

## 3. 基本体験

1. 起動すると**都市画面**。上空から自分の都市を眺める。都市は模擬で動き、住民が暮らし、働き、家賃を払い、市長（学習者）を支持したり離れたりする
2. 道路を引き、区画を塗り、施設を置いて都市を形づくる。施設は置いてもすぐには建たず、**申請**になる
3. 申請には、近くの住民や集団が理由を挙げて反対する。公聴会で、譲歩する・説明する・押し切るのどれかで答え、議会 7 人の採決で可決されれば着工する
4. 施設を選ぶと情報パネルが開き、関係する IT スキルと学習が示される。公聴会の論点からも、関係する学習へ進める
5. 学習を始める（施設からでも、学習ライブラリからでも、公聴会からでも、どの分野からでも。審議や選挙に関係なく、いつでも）
6. 解説 → 理解 → クイズ → 実戦 → 結果 → まとめ、と進み、XP とスキルを得る
7. 都市に戻ると、学習の成果で開発資金が増え、施設を育てられ、公聴会で出せる「説明する」の手が増えている
8. 都市の課題（ミッション・請願・反対の論点・表示切替が示す「なぜ支持率が下がったか」）が、次に学ぶとよいことを示す
9. 4 年ごとの選挙で、任期の功績が問われる。落選しても学習の記録は消えず、同じ都市で再び立つか、新しい都市で始められる
10. これを繰り返し、小さな村が技術都市へ育つ

## 4. 機能一覧

| 区分 | 機能 |
|---|---|
| 都市 | 2.5D の都市表示 / 拡大縮小・移動・回転（90 度単位）/ 道路の敷設 / 区画の指定（住宅・商業・オフィス・工業）/ 施設・公共サービス・発電所・公園の配置 / 建物の選択と情報パネル / 発展段階と景観の変化 / 時間（止める・1 倍・2 倍・3 倍） |
| 都市の模擬 | 住民（区画の建物ごとの層の分布）/ 事業者 / 地価 / 家賃と手頃さ / 雇用と通勤 / 税収 / 電力（発電所・送電・停電）/ 公共サービスの行き届き / 需要（住宅・商業・工業）/ 満足と支持率 |
| 表示切替 | ヒートマップ（地価・家賃・人口の密度・騒音・雇用・公共サービス・電力・支持率・学習の進み・交通・発展段階）/ グラフ（人口・資金・財政・支持率・雇用）/ 平易な言葉の説明（なぜ支持率が動いたか） |
| 市政 | 許認可（申請 → 用途地域の審査 → 反対の受付 → 公聴会 → 議会の採決 → 異議申し立て → 着工 → 完成）/ 反対（集団・理由・模擬から計算した反対率）/ 公聴会（譲歩・説明・押し切る）/ 議会 7 席の採決 / 異議申し立て / 選挙と任期と公約 / 政治資本 / 請願（受信箱）/ 予算と税率 / 市内新聞 / 褒賞 / 始め方の選択（反対の組織化の度合い） |
| 学習 | 学習ライブラリ（全分野の一覧と検索）/ 知識グラフの表示 / 推奨学習順 / 前提・関連・次に学ぶの表示 / レッスン（7 段の流れ）/ 用語の説明 / クイズ（選択・状況判断・原因特定・結果予測・用語）/ 実戦（仮想端末・模擬環境）/ エラー学習 / 復習の提案 |
| 成長 | XP / スキル（分野ごと、学習履歴と理解度から計算）/ エンジニアとしての称号 / 学習履歴 |
| ゲーム | ミッション / 施設のアップグレード（申請）/ 開発資金（学習から）と財政（税収から）/ 都市規模 / おすすめ / 通知 |
| 保存 | 自動保存（ブラウザ内）/ 保存データの書き出しと読み込み / 最初からやり直す |
| 設定 | 音 / 動きを減らす / 文字の大きさ / 表示品質 |

## 5. 非機能要件

| 項目 | 要件 |
|---|---|
| 性能 | 1920×1080 で都市画面が 60fps を目指し、最低 30fps。初回表示 3 秒以内（一般的な回線と PC で）。都市の模擬は描画と別の流れ（Web Worker）で動かし、模擬の重さで都市画面を重くしない（`docs/architecture.md` 9 章） |
| 画面 | PC 向けの横長。1280×720 未満では「PC の大きな画面で遊んでください」と案内する（スマホ向けには作らない） |
| ブラウザ | 最新の Chrome・Edge・Firefox・Safari |
| 見やすさ | 文字と地の明るさの差（4.5:1 以上）。キーボードだけで主要な操作ができる。動きを減らす設定 |
| オフライン | 一度開いた後は、学習と都市の操作が回線無しで続けられることを目指す |
| 保守 | コンテンツはデータとして追加できる。アプリ本体の改修無しに分野・レッスン・施設・ミッションを足せる |
| 安全 | 実戦はブラウザ内の模擬環境で行う。利用者の PC や外部のサーバには何もしない |

## 6. 無料要件

- 利用者は完全無料で遊べる。課金の仕組みは作らない
- 運営側も無料で公開できる。有料サーバ・有料 API・従量課金 API・有料 DB・有料 SaaS・有料 AI API・有料素材を前提にしない
- 詳細は `docs/free-services.md`

## 7. 公開要件

- 公開先は GitHub Pages（`https://swallowsaba.github.io/swallow/devlearn-arena/`）
- HTTPS で配信される
- 秘密情報を公開しない
- 公開前の確認項目は `docs/deployment.md`
