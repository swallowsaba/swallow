# プロダクト仕様

## 1. 目的

**IT エンジニアとして成長すると都市が成長する、PC 向け都市開発シミュレーションゲーム**を作る。
学習者は、都市を育てたい・次の施設を作りたい・新しい技術を知りたい、という動機で学び続け、
実際のエンジニアが持つ「理解する → 操作する → 結果を見る → 問題を見つける → 原因を調べる → 直す → 確かめる」力を身に付ける。

作らないもの: IT 学習サイトをゲーム風に飾ったもの。

## 2. 対象者

- 主: IT 未経験〜初級のエンジニア志望者、新人エンジニア（中学生以上が読める日本語）
- 副: 特定分野（Kubernetes・ネットワークなど）を補強したい現役エンジニア
- 利用環境: PC のブラウザ（横長の画面、マウスとキーボード）。1280×720 以上。推奨 1920×1080

## 3. 基本体験

1. 起動すると**都市画面**。上空から自分の都市を眺める
2. 道路を引き、区画を塗り、施設を置いて都市を形づくる
3. 施設を選ぶと情報パネルが開き、関係する IT スキルと学習が示される
4. 学習を始める（施設からでも、学習ライブラリからでも、どの分野からでも）
5. 解説 → 理解 → クイズ → 実戦 → 結果 → まとめ、と進み、XP とスキルを得る
6. 都市に戻ると、学習の成果で施設が育ち、新しい建物や機能が増えている
7. 都市の課題（ミッション）が、次に学ぶとよいことを示す
8. これを繰り返し、小さな町が技術都市へ育つ

## 4. 機能一覧

| 区分 | 機能 |
|---|---|
| 都市 | 2.5D の都市表示 / 拡大縮小・移動・回転（90 度単位）/ 道路の敷設 / 区画の指定 / 施設・公園の配置 / 建物の選択と情報パネル / 発展段階と景観の変化 / 表示の切り替え（学習の進み・人口など） |
| 学習 | 学習ライブラリ（全分野の一覧と検索）/ 知識グラフの表示 / 推奨学習順 / 前提・関連・次に学ぶの表示 / レッスン（7 段の流れ）/ 用語の説明 / クイズ（選択・状況判断・原因特定・結果予測・用語）/ 実戦（仮想端末・模擬環境）/ エラー学習 / 復習の提案 |
| 成長 | XP / スキル（分野ごと、学習履歴と理解度から計算）/ エンジニアとしての称号 / 学習履歴 |
| ゲーム | ミッション / 施設のアップグレード / 開発資金 / 都市規模 / おすすめ / 通知 |
| 保存 | 自動保存（ブラウザ内）/ 保存データの書き出しと読み込み / 最初からやり直す |
| 設定 | 音 / 動きを減らす / 文字の大きさ / 表示品質 |

## 5. 非機能要件

| 項目 | 要件 |
|---|---|
| 性能 | 1920×1080 で都市画面が 60fps を目指し、最低 30fps。初回表示 3 秒以内（一般的な回線と PC で） |
| 画面 | PC 向けの横長。1280×720 未満では「PC の大きな画面で遊んでください」と案内する（スマホ向けには作らない） |
| ブラウザ | 最新の Chrome・Edge・Firefox・Safari |
| 見やすさ | 文字と地の明るさの差（4.5:1 以上）。キーボードだけで主要な操作ができる。動きを減らす設定 |
| オフライン | 一度開いた後は、学習と都市の操作が回線無しで続けられることを目指す |
| 保守 | コンテンツはデータとして追加できる。アプリ本体の改修無しに分野・レッスン・施設・ミッションを足せる |
| 安全 | 実戦はブラウザ内の模擬環境で行う。利用者の PC や外部のサーバには何もしない |
