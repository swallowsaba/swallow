# 完成条件

「ページが表示される」は完成ではない。この文書の全項目を満たして完成とする。
確かめ方は `docs/testing-strategy.md`。

## 1. ゲームループ（最重要）

次を、利用者の操作だけで途切れずに通せる。E2E で自動化し、撮影でも確かめる。

```text
都市を表示 → 都市を操作 → 建物を選択 → 学習コンテンツを選択 → 解説 → 理解 → クイズ
→ 実戦 → 結果 → まとめ → XP / スキル → 都市が発展
```

- [ ] G1. 起動直後に都市画面が出る（学習サイトのトップではない）
- [ ] G2. 移動・拡大縮小・回転ができる
- [ ] G3. 施設を選ぶと情報パネルが出て、おすすめの学習から始められる（申請中・工事中・停電中の施設でも）
- [ ] G4. 7 段を通せる。途中で中断・再開できる
- [ ] G5. 終えると XP とスキルが仕様の式通りに増える
- [ ] G6. 都市に戻ると、変化（増えた開発資金・新しく出せる説明・上げられるようになった施設の Lv・完成した建物・区画の成長）が見て分かり、その場所へカメラが寄る

## 7. 都市の模擬と市政（`docs/decisions.md` D-20）

仕組みは `docs/game-design.md` 13〜27 章、画面は `docs/ui-design.md` 10・11 章。Phase は `docs/development-plan.md` G1〜G12。

### 7.1 市政のゲームループ（最重要）

次を、利用者の操作だけで途切れずに通せる。E2E で自動化し、撮影でも確かめる。

```text
都市を表示 → 施設を置く → 申請 → 反対の集団と理由が立つ → 公聴会の論点から学習を選択 → 7 段 → スキル段階が上がる
→ 公聴会に戻り、新しく出せる説明で答える → 議会の採決で可決 → 着工 → 完成 → 模擬の値と支持率が動き、その理由が説明に出る
```

- [ ] S1. 上のループを 1 本の E2E で通せる。途中でレッスンを中断・再開しても、公聴会は待っている
- [ ] S2. **学習にロックが無い。** 申請中・公聴会の途中・申し立て中・赤字・停電・落選の後のどの状態からも、レッスン・ミッション・学習ライブラリを開ける
- [ ] S3. **スキルが無くても通せる。** スキル 0 のまま、譲歩と政治資本だけで申請を可決させられる

### 7.2 模擬と因果

- [ ] S4. 住民（区画の建物ごとの 12 層）・事業者・地価・家賃と手頃さ・雇用と通勤・税収が週ごとに動き、互いに影響し合う（施設の完成 → 雇用 → 空き室 → 家賃 → 低の帯の引っ越し → 支持率、の連鎖が値で追える）
- [ ] S5. 時間を止める・1 倍・2 倍・3 倍にでき、都市画面が前に出ていない間（レッスン・大きな窓・隠れた窓）は止まる
- [ ] S6. **決定性。** 同じ seed と同じ命令の列から、同じ支持率・反対率・採決・選挙の結果になる。`src/sim` に `Math.random`・`Date.now` が無い
- [ ] S7. **因果が見える。** 支持率の 4 週の変化を、1〜2 行の平易な言葉（どれだけ・どの決定の・どの影響で）で示し、文の数字が内訳と一致する。押すと原因の場所と要因のヒートマップに切り替わる
- [ ] S8. ヒートマップ（地価・家賃・人口の密度・騒音・雇用・公共サービスの行き届き・電力・支持率と、今ある 4 つ）とグラフ（人口・開発資金・財政・支持率・雇用）が見られ、値に単位がある

### 7.3 許認可と審議

- [ ] S9. 施設・公共サービス・発電所・褒賞の建物・アップグレード・人の住む所の隣の用途地域の変更が申請になり、`docs/game-design.md` 15.2 の段階と日数で進む。道路・空き地への区画・公園は即時
- [ ] S10. 申請ごとに、集団・理由・反対率が模擬から計算され、理由ごとの内訳の合計が反対率と一致する。置く場所を変えると反対率が変わる
- [ ] S11. 公聴会で、論点ごとに譲歩・説明・押し切るを出せる。**譲歩は完成した建物の性質として模擬に効く**（ヒートマップで見える）
- [ ] S12. 説明の候補がスキル段階で増え、質（確か・一部・誤り）で効きが違い、選んだ後に理由と学べるレッスンが出る
- [ ] S13. 議会 7 人が、それぞれの論点で賛否を出し、各人の理由が 1 行で出る。賛成 4 以上で可決。公聴会の答え方で賛否が変わる
- [ ] S14. 異議申し立てが条件を満たした時だけ立ち、追加の譲歩か政治資本で取り下げさせられる

### 7.4 選挙と市政

- [ ] S15. 4 年ごとに選挙があり、層ごとの支持と投票率で得票率が決まる。落選すると敗因（層・要因・決定）が示され、同じ都市で再び立つ・新しい都市で始めるを選べる。**どちらでも学習の記録が変わらない**
- [ ] S16. 任期の終わりに功績の一覧が出る。公約を 2 つ選べ、果たすと政治資本と信頼が動く
- [ ] S17. 政治資本を、公約・ミッション・支持率の上昇で得て、押し切る・申し立てを抑える・議員を説得するに使える
- [ ] S18. 請願が模擬の条件で届き、受理・拒否・保留で、資金・支持率・集団との関係が動く。受理の中身が模擬に効く
- [ ] S19. 予算の窓で週ごとの収支と税率を見て変えられる。税率が支持と事業者に効く。開発資金（学習から）と財政（税収から）が分かれ、赤字が学習と開発資金に効かない
- [ ] S20. 市内新聞「市民新報」が出来事を記事にし、過去の記事を読み返せる。不祥事は市長の決定からだけ出る
- [ ] S21. 需要（住宅・商業・工業）が模擬から計算され、区画の道具で見られる
- [ ] S22. 発電所と送電で電気が届き、足りないと地区が順に止まり、建物が働かない（施設からの学習は止まらない）。データセンターなどが多く使う
- [ ] S23. 公共サービス（警察・消防・学校・診療所・公園）が距離で行き届き、満足と地価に効く。公共サービスと IT 施設の役割と財布が分かれている
- [ ] S24. 人口と支持率の節目で褒賞の建物が建てられるようになる（学習には掛からない）
- [ ] S25. 新しく始める時に、反対の組織化の度合いを 3 つから選べる（初回も都市画面が主画面のまま）
