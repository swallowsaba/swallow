# 完成条件

「ページが表示される」は完成ではない。この文書の全項目を満たして完成とする。
確かめ方は `docs/testing-strategy.md`。

## 1. ゲームループ（最重要）

次を、利用者の操作だけで途切れずに通せる。E2E で自動化し、撮影でも確かめる。

```text
都市を表示 → 都市を操作 → 建物を選択 → 学習コンテンツを選択 → 解説 → 理解 → クイズ
→ 実戦 → 結果 → まとめ → XP / スキル → 都市が発展
```

- [ ] G1. 起動直後に都市画面が出る（学習サイトのトップではない）
- [ ] G2. 移動・拡大縮小・回転ができる
- [ ] G3. 施設を選ぶと情報パネルが出て、おすすめの学習から始められる
- [ ] G4. 7 段を通せる。途中で中断・再開できる
- [ ] G5. 終えると XP とスキルが仕様の式通りに増える
- [ ] G6. 都市に戻ると、変化（施設の Lv・区画の成長・新しい建物）が見て分かり、その場所へカメラが寄る

## 2. 機能

- [ ] F1. 道路（直線・曲線・橋）・区画・施設・公園を置け、置けない理由が出る
- [ ] F2. 区画の建物が条件に応じて建ち、育つ
- [ ] F3. 全施設が Lv1〜Lv5 の見た目を持つ
- [ ] F4. 発展段階が技術力と都市規模で上がり、霧が晴れ、見た目が変わる
- [ ] F5. ミッション 6 本が受けられ、達成でき、報酬が都市に現れる
- [ ] F6. 学習ライブラリ・知識グラフ・成長画面・用語集・設定が使える
- [ ] F7. 保存・読み込み・書き出し・やり直しができる

## 3. UI

- [ ] U1. `docs/visual-design.md` 8 章の V1〜V11 を全画面で満たす
- [ ] U2. 1920×1080 と 1280×720 で崩れない。1280×720 未満は案内が出る
- [ ] U3. 都市画面の常時の UI が画面の 20% 以内
- [ ] U4. 指定のフォントだけで表示される
- [ ] U5. 主要な操作がキーボードでできる。文字と地の明るさの差が 4.5:1 以上
- [ ] U6. 都市画面が 1920×1080 で 30fps 以上（目標 60fps）
- [ ] U7. 都市画面の左下のミニマップが、全体と今の視野を示し、押すとその場所へカメラが動く。設定で消せる（`docs/ui-design.md` 3 章）

## 4. 学習

- [ ] L1. どのレッスンも、前提を学んでいなくても始められる（ロックが無い）
- [ ] L2. 推奨学習順・推奨前提・関連・次に学ぶとよいが表示される
- [ ] L3. 全レッスンが 7 段を持ち、解説の前にコマンドを打たせない
- [ ] L4. 本文の専門用語が全て用語集にあり、押すと説明が出る
- [ ] L5. クイズに 3 種類以上の形があり、誤答に理由がある
- [ ] L6. 実戦の判定が模擬環境の状態で行われ、最後のヒントで必ず通る
- [ ] L7. エラーで「内容 → 原因候補 → ヒント → 再挑戦」が出て、ゲームオーバーにならない
- [ ] L8. コンテナの概念が Docker より先に、Kubernetes が独立分野として段階的にある
- [ ] L9. 初回公開の範囲（`docs/decisions.md` Q-04）のレッスンが揃っている

## 5. ゲーム

- [ ] P1. XP の稼ぎ防止が効いている（同じレッスンの繰り返しで XP がほぼ増えない）
- [ ] P2. スキルの画面で「何をしたからこの値か」が見える
- [ ] P3. どの分野の組み合わせでも発展段階を上げられる（特定の分野が必須でない）
- [ ] P4. 報酬の表示に「何ができるようになったか」が添えられている

## 6. 公開

- [ ] D1. GitHub Pages の公開 URL で全機能が動く（直リンク・リロードを含む）
- [ ] D2. build・test・lint・型検査が CI で通る
- [ ] D3. 秘密情報の検査で何も見つからない
- [ ] D4. 外部の有料サービスに依存していない（`docs/free-services.md` の一覧と一致）
- [ ] D5. 素材とフォントの出典とライセンスが `CREDITS.md` に揃っている
