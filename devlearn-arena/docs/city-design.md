# 都市デザイン

ゲームの規則と数値は `docs/game-design.md`、描画の技術は `docs/architecture.md`、色と字は `docs/visual-design.md`。
この文書は**都市の構造と、何がどう建ち、どう見えるか**を決める。

## 1. 都市構造

- 都市は等角投影（2:1）の格子の上にある。1 マス = 道路 1 本分の幅
- 地図は 96×96 マス。初めは中央の 24×24 マスが使える。発展段階で外側の霧が晴れる
- 地形: 浮いた島の地盤（厚みのある縁）・海・川（蛇行）・丘（高さ 0〜3 段の起伏）。海岸線と川は曲線で、階段状にしない
- 層: 地面 → 水 → 道路 → 区画の地面 → 建物と木 → 車と人 → 名札 → UI

## 2. 道路

| 種類 | 幅 | できる段階 | 見た目 |
|---|---|---|---|
| 細い道 | 1 マス | 村 | 路面・縁石・白線なし |
| 一般道 | 1 マス | 村 | 路面・縁石・中央線・横断歩道 |
| 大通り | 2 マス | 地方都市 | 中央分離帯と並木・車線 2 本ずつ |
| 橋 | — | 町 | 川を渡る所に自動で架かる。欄干と影 |
| ロータリー | 3×3 | 地方都市 | 環道と中央の緑地 |

- 道路はドラッグで引く。直線と、曲線（始点・制御点・終点）を引ける
- 交差点は自動でつなぐ。行き止まりには転回場を描く
- 建物と区画は、道路に面していないと機能しない（建たない）

## 3. 区画

学習者が塗る。中の建物は自動で建ち、育つ（`docs/decisions.md` D-03）。

| 区画 | 建つもの | 育ち方 |
|---|---|---|
| 住宅 | 戸建て → 低層集合住宅 → 中層 → 高層 | 雇用（オフィス・施設）と周辺の公園で育つ |
| 商業 | 小さな店 → 商店街 → 商業ビル | 人口で育つ |
| オフィス | 小さな事務所 → オフィスビル → 高層オフィス | 技術力で育つ |

## 4. 施設

学習者が置く。**施設は学習の入口であり、成果が形になる場所。学習を制限しない**（`docs/decisions.md` D-02）。

| 施設 | 対応する分野 | 大きさ | 見た目の特徴（Lv が上がると加わるもの） |
|---|---|---|---|
| 市立 IT 学院 | IT 基礎 | 3×3 | 校舎と時計塔 → 図書館棟 → 講堂 |
| サーバ施設 | Linux | 2×2 | 平屋のサーバ棟と冷却塔 → 増築棟 → 発電設備 |
| ネットワークセンター | ネットワーク | 2×2 | 局舎と鉄塔 → アンテナ → 光ケーブルの地中線 |
| Web 施設 | Web / HTTP | 2×2 | ガラス張りの低層ビル → 看板 → 展望フロア |
| セキュリティセンター | TLS / セキュリティ | 2×2 | 堅牢な建物と門 → 監視カメラ → 塔 |
| 開発オフィス | Git | 2×2 | 中層のオフィス → 屋上庭園 → 渡り廊下 |
| デプロイセンター | CI/CD | 3×2 | 工場とベルトコンベア → 出荷口 → 自動倉庫 |
| コンテナ施設 | コンテナ / Docker | 3×3 | 港とクレーン、積まれたコンテナ → 倉庫 → 第二埠頭（Docker 工房） |
| クラスタ施設 | Kubernetes | 3×3 | 同じ形のビル群（ノード）と管制塔 → 棟の追加 → ヘリポート |
| データセンター | データベース | 3×2 | 窓の少ない大きな建物と空調 → 増設棟 → 予備電源 |
| クラウドセンター | クラウド / インフラ | 3×3 | 雲を模した屋根の建物 → 複数棟の分散 → 別地区の分館 |
| 監視・運用センター | 監視 | 2×2 | 大きな窓の管制室とアンテナ → 大型画面 → 塔 |
| DevOps 推進本部 | DevOps | 2×2 | 中層ビルと広場 → 連絡橋で他施設とつながる |
| インシデント対応本部 | トラブルシューティング | 2×2 | 消防署に似た建物と車庫 → 出動車両 → 指令塔 |
| 研究施設 | 研究（総合演習） | 3×3 | ドーム屋根の研究所 → 実験棟 → 展示ホール |

- レベル 1〜5。レベルごとに見た目を変える（上の「加わるもの」）。Lv1 と Lv5 は一目で違うこと
- 施設を押すと情報パネル（`docs/ui-design.md`）: 名前・レベル・対応する分野・関係するスキルの値・おすすめのレッスン・ミッション・アップグレード
- 公園・広場・並木・噴水・記念碑（ミッションの報酬）も置ける

## 5. 発展段階と見た目

規則は `docs/game-design.md` の 6 章。見た目の変化をここで決める。

| 段階 | 見た目 |
|---|---|
| 1 村 | 細い道と戸建て。畑と木が多い。施設は小さな Lv1 |
| 2 町 | 一般道と橋。商店街。低層集合住宅。公園 |
| 3 地方都市 | 大通りとロータリー。中層ビル。施設が Lv3 で大きく |
| 4 中核都市 | 高層ビル群。鉄道（景観）。窓の数と細部が増える |
| 5 技術都市 | 超高層とランドマーク。施設群が連絡橋でつながる |

- 学習の直後に都市へ戻ったら、変化のあった場所へカメラが寄り、光の輪と名札で何が変わったかを示す

## 6. 動き

- 車が道路を走り、人が歩道を歩く（数は都市規模に応じて増える）
- 施設ごとの動き: コンテナ施設のクレーン、デプロイセンターのベルトコンベア、クラスタ施設の窓の点灯（稼働の表現）、ネットワークセンターの光る線
- 建設は 3 段階（基礎 → 骨組み → 完成）で見せる
- 動きを減らす設定では、動きを止める

## 7. 疑似 3D（2.5D）の描き方

- **等角投影（横 2 : 縦 1）。** 光は左上から。上面が最も明るく、左面が中間、右面が最も暗い
- 建物は必ず次を持つ: **奥行き・左右の側面・屋根（平屋根なら縁と設備、勾配屋根なら 2 面以上）・窓（面の傾きに沿う）・入口・外観の細部（庇・看板・設備・手すりなど 3 つ以上）・接地の影・道路との接続（敷地の舗装や車寄せ）・周辺環境（木・植え込み・街灯）**
- 四角形と三角形を重ねただけの家は禁止。CSS の図形で建物を作らない。絵文字を使わない
- 施設は自作 SVG（`src/city/assets/`）で描く。区画の建物は同じ描き方の規則で手続き的に生成してよい（見た目は自作 SVG と揃える）
- 名札は互いに重ならず、建物を隠さない（`docs/ui-design.md`）

## 8. 配置の規則

- 置ける所は緑の枠、置けない所は赤の枠と理由（道路に面していない・重なる・霧の中・資金が足りない）
- R キーで 90 度回転、Esc で取り消し
- 取り壊しは確認してから。施設を壊しても学習の記録は消えない
- 配置の判定は `src/city/` の純粋な関数で行い、テストする
