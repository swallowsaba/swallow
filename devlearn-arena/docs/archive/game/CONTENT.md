# 選手と試合の一覧

**エンジンが実装しているコマンドだけが選手になれる。** 下の表で、エンジンに無いコマンドがあれば、
先に `src/engines/` に本物の仕組みとして実装し、テストを書いてから選手にする。

## 1. 選手

### シェル道場

| 選手 | 役割 | 役目（札に出す一文） | 技 |
|---|---|---|---|
| `ls` | 探索 | 今いる通りに何があるかを見回す | `-l` 詳しく / `-a` 隠れた物も / `-h` 大きさを読みやすく / `-t` 新しい順 |
| `cd` | 移動 | 別の通り（ディレクトリ）へ歩いて移る | `..` 一つ上へ / `~` 自分の家へ / `-` 前にいた所へ / `/` 街の入口へ |
| `pwd` | 探索 | 今どの通りにいるかを確かめる | — |
| `mkdir` | 移動 | 新しい通りを作る | `-p` 途中の通りもまとめて |
| `cat` | 加工 | 家（ファイル）の中身を読み上げる | `-n` 行番号 / `>` 書き出す先 / `\|` 次の選手へ渡す |
| `cp` | 移動 | 家を写して別の場所に建てる | `-r` 通りごと写す |
| `mv` | 移動 | 家を別の場所へ移す、名前を変える | — |
| `rm` | 移動 | 家を取り壊す | `-r` 通りごと / `-f` 確かめずに |
| `find` | 探索 | 街中を歩き回って条件に合う物を探す | `-name` 名前で / `-size` 大きさで / `-mtime` 古さで / `-exec` 見つけた物に何かする |
| `grep` | 加工 | 大量の文から欲しい行だけを拾う | `-i` 大文字小文字を区別しない / `-r` 中を丸ごと / `-n` 行番号 / `-v` 一致しない行 |
| `sed` | 加工 | 文字列を置き換える | `s///` 置き換え / `-i` その場で書き換え |
| `cut` | 加工 | 行の決まった列だけ切り出す | `-d` 区切り文字 / `-f` 列 |
| `sort` | 加工 | 行を並べ替える | `-n` 数の順 / `-r` 逆順 / `-h` 大きさの順 |
| `uniq` | 加工 | 重なった行をまとめる | `-c` 数える |
| `wc` | 探索 | 行や文字を数える | `-l` 行の数 |
| `head` / `tail` | 加工 | 先頭 / 末尾だけ見る | `-n` 行数 / `-f` 増えるのを追う（tail） |
| `du` | 探索 | どの通りが場所を取っているか量る | `-h` 読みやすく / `-s` 合計だけ |
| `df` | 探索 | ディスク全体の空きを見る | `-h` 読みやすく |
| `truncate` | 移動 | 家を壊さず中身だけ空にする | `-s 0` 空にする |
| `echo` | 加工 | 文字を書き出す | `>` / `>>` |
| `xargs` | 加工 | 受け取った物を次の選手の引数にする | — |
| `tee` | 加工 | 流れを分けて書き出しもする | `-a` 追記 |

### Git 資料室

`git init` `git status` `git add` `git commit` `git log` `git diff` `git branch` `git switch` `git merge`
`git rebase` `git stash` `git reset` `git restore` `git revert` `git cherry-pick` `git tag`
`git remote` `git push` `git fetch` `git pull` `git bisect`

役割: 状態を見るもの（status, log, diff）は探索、記録するもの（add, commit, tag）は記録、
枝を動かすもの（branch, switch, merge, rebase, reset, revert, cherry-pick）は移動、
遠くとやり取りするもの（remote, push, fetch, pull）は通信。技はオプション（`--staged` `--oneline` `-c` `--soft` `--hard` `--force-with-lease` など）。

### 通信室

`ping` `traceroute` `curl` `dig` `ip` `ipcalc` `netstat`
役割は通信。技: `curl -v` / `curl -I` / `dig +short` / `ip route` / `ip link set ... down` など。

### k8s 訓練場

`kubectl get` `kubectl describe` `kubectl run` `kubectl create` `kubectl apply` `kubectl delete`
`kubectl scale` `kubectl rollout` `kubectl logs` `kubectl label` `kubectl set` `kubectl cordon`
`kubectl drain` `kubectl expose`
役割: get と describe と logs は探索、それ以外は運用。技: `-o wide` `-o yaml` `-n` `--replicas` `undo` など。

### GitHub 会議室

`gh pr create` `gh pr view` `gh pr review` `gh pr checks` `gh pr merge` `gh workflow` `gh protect`
役割は協働。技: `--approve` `--request-changes` `--squash` `--rebase` など。

## 2. 試合（障害対応）

既存の任務のうちボス（`kind: 'boss'`）を試合に作り直す。足りない分野は新しく作る。
**どの試合も、ピッチに描くものと、勝ち・引き分け・負けの条件をはっきり決める。**

| リーグ | 試合 | 相手（障害） | ピッチに描くもの | 勝ち | 引き分け |
|---|---|---|---|---|---|
| 地域 | 迷子の荷物 | 深いディレクトリの奥に埋もれた設定ファイル | 通り（ディレクトリ）が区域、目的の家 | 目的のファイルを見つけて中身を答える | 見つけたが余計なファイルも開いた |
| 地域 | ディスク満杯 | 膨らみ続けるログ | 区域＝ディレクトリ、相手＝大きなファイル | 空き 30% 以上、サービス稼働中 | `rm` で消して空きが戻らない |
| 地域 | 消えた行 | ログの中に紛れた障害の手掛かり | 行の流れ、拾った行 | 原因の行を見つけて数を答える | 全行を読んで見つけた |
| 地域 | 権限の壁 | 実行できないスクリプト | 家の鍵 | 実行できるようにする | 誰でも書き換えられる権限にした |
| 2 部 | 戻せない修正 | 壊れた変更がコミットされた | コミットの並び | 壊れた変更を打ち消して動く状態に戻す | 履歴を書き換えて戻した |
| 2 部 | 衝突 | 2 人の変更がぶつかる | 2 本の枝 | 衝突を解いて統合する | 片方の変更を捨てた |
| 2 部 | 繋がらない | ping は通るが curl が失敗する | 機器とリンク、荷車 | 原因（待ち受けていない）を特定する | 全ての機器を再起動した |
| 2 部 | 名前が引けない | DNS の設定の誤り | 名前を番号にする窓口 | 名前で繋がるようにする | IP で直接繋いで済ませた |
| 1 部 | Pod が起動しない | 存在しないイメージ | ビル（ノード）と住人（Pod） | 正しいイメージで Running にする | Pod を手で作り直した |
| 1 部 | Endpoints が空 | Service のセレクタの誤り | バス停と住人 | Service から Pod に繋がる | Pod のラベルを片っ端から書き換えた |
| 1 部 | 停電 | ノードの停止 | ビル | 住人を別のビルへ移し、サービスを保つ | 一時的に全て止まった |
| 1 部 | 壊れた変更の混入 | CI を通さずにマージされた | PR と検査の流れ | 保護を掛け、壊れた変更を差し戻す | 保護を掛けずに直した |

## 3. 練習

- 各施設に 5〜10 個の練習を用意する。各練習は 1〜3 人の選手を鍛える
- 既存の任務のうちボスでないものを、学びの流れの 5 段に作り直して練習にする
- 足りない選手の練習は新しく作る
- 各練習の「体験」は `docs/games/` の遊びを、その練習の範囲に切り出して使う
