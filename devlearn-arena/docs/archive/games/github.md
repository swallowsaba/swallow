# GitHub の街の遊び：共同の設計図

## 学ばせたいこと
Pull Request、レビュー、CI、ブランチの保護、マージ

## 遊び
学習者は 3 人の設計技師のまとめ役。3 人が同じ設計図を直している。

1. 3 人が直接、本物の設計図を書き換える。誰かが別の人の変更を上書きする
2. 誰かが間違った変更（道の途中で途切れる）を入れ、街が壊れる。気づいた時には手遅れ
3. 直しの提案を受け取る窓口を作ると、提案を見てから本物に入れられる

## 学習者の行動
- 提案を開いて中身を見る
- 提案を通す／差し戻す
- 自動検査の機械を置く（道が途切れていないか調べる）

## 失敗
- 壊れた変更を通した: 街の道が途切れ、車が止まる

## 達成
- 5 件の提案を、壊れた変更を 1 件も通さずに処理する

## 次の「登場」へのつなぎ
提案の窓口（Pull Request）、中身を見て判断（レビュー）、
自動検査の機械（CI）、本物を直接触らせない決まり（ブランチの保護）。
