# 遊びの設計書

各分野の「体験」の段は、ここに書いた遊びをそのまま実装する。説明図にしない。
どの遊びも次を満たすこと（`src/lesson/experience/*.test.ts` で検査する）。

- 学習者の行動が 3 種類以上ある（クリック、ドラッグ、選択 など）
- **失敗できる。** 失敗したら街が反応し、なぜ失敗したかが見える
- **達成できる。** 達成条件がはっきりしている
- 60〜120 秒で終わる。後半ほど難しくなる
- 遊びで困ったことが、次の「登場」で出てくる仕組みの必要性そのものになっている
- 用語は出さない（用語は「登場」の段で初めて出す）
- 遊びの状態は純粋な TypeScript の模型で持ち、描画は 3D の街で行う
