# Kubernetes の街の遊び：住人の案内係

## 学ばせたいこと
ノード、Pod、スケジューリング、宣言的な管理（あるべき数を保つ）、再作成

## 遊び
学習者はビル街の案内係。店（アプリ）を開きたい住人が次々に来るので、空いたビルへ案内する。

1. 住人が 1 人ずつ来る。空きのあるビルへドラッグで案内する。ビルには定員がある
2. 住人が来る間隔が短くなる。定員を超えるビルには入れられない
3. ビルが停電する。中の住人が路頭に迷い、手で別のビルへ引っ越させないといけない。
   店主は「常に店を 3 軒開けておいて」と言っている

## 学習者の行動
- 住人をビルへドラッグして案内する
- ビルをクリックして空き具合を見る
- 停電したビルから住人を引っ越させる

## 失敗
- 定員超過: ビルに入れず、住人が赤く揺れる
- 開いている店が 3 軒を下回る: 店主の満足度が下がる

## 達成
- 90 秒間、開いている店を 3 軒以上に保つ

## 次の「登場」へのつなぎ
手が追いつかなくなったところで、**監督の建物**と**配置係の建物**が街に建つ。
「あるべき数（3 軒）を伝えておけば、足りなくなったら監督が気づき、配置係が空いたビルを選ぶ」
→ ここで初めて Pod、ノード、スケジューラ、コントローラという言葉を出す。
