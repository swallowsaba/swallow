**上から順に実装し、終えた項目を [x] にする。** 各項目のあと `npm run verify` を通す。最後に `npx playwright test --workers=1` と `npm run build`。

## 要件（ユーザー指示）

- 右側のデザインと仕組みは一切捨てて一から作り直す（等角の街 CityScene、街/いまの状態の切替、FsGame などのドット絵ゲーム画面は廃止）。
- 市長（プレイヤー）が自分で街を作る：道路を引く、住宅・商業・工業の区画を塗る、施設を好きな場所に置く、撤去する。予算、需要（住宅/商業/工業）、時間の経過、住民の声がある。Cities: Skylines と同じ操作感。
- 説明を聞いたあと、理解度（判断問題・理解度チェックの正解）とコマンド（手順の通過・任務の完了）で予算と整備が進み、街が徐々に大きく・整っていく。
- 見た目は 3D（three.js）。回転・ズーム・移動、影、昼夜、車が走る。
- 左側（説明 → 要望 → コマンド、ヒントは左上）、「街」表記、市長の立場はそのまま。冒険・組織の言葉は使わない。

## 設計

### シミュレーション `src/engines/city/`（純粋関数・決定論。Date / Math.random 禁止）
- 36×36 マス。地形（草地・水・林）はカテゴリごとの種から生成。西の端から幹線道路が入っている。
- 道具：道路（ドラッグで L 字、1 マス ¥10、橋 ¥40）/ 住宅・商業・工業（道路から 3 マス以内の空き地を矩形で塗る、無料）/ 公園（¥80）/ 施設（学んで建設を決めた施設を 2×2 で置く、道路に接する、¥400）/ 撤去。
- 1 日ごと：幹線につながる道路網を調べ、つながった区画だけが需要に応じて育つ（段階 1〜4）。段階の上限は地価で決まる：道路=1、施設の範囲内=2、地価 2 以上=3、地価 3 以上=4。
- 地価：施設の範囲（半径 = 4 + 稼働率×6）、稼働率 50% 以上・フル稼働でさらに加点、公園で加点、工業の近くの住宅は減点。
- 需要：住宅は働き口と満足度、商業は人口、工業は商業から決まる。税収は人口と働き口、維持費は施設・道路・公園。
- 報酬（一度だけ、キーで重複防止）：施設の建設決定 ¥600、判断問題の正解 ¥200（一度間違えたら ¥80）、理解度チェックの正解 ¥120（¥50）、手順の通過 ¥80（飛ばしたら無し）、任務の完了 ¥250。
- 住民の声：道路が無い、区画が無い、道路につながっていない、需要が高い、施設の配置待ち、まだ稼働していない施設、未着手の施設の困りごと。

### 保存
- `cities: Record<track, { terrain 以外の tiles, levels, facilities[{id,x,y}], money, day, earned[] }>`（地形は種から毎回作る）。

### 右側 `src/features/city3d/`
- `CityPane`（HTML の操作盤。jsdom でテストする）：上＝予算・人口・満足度・日付・速度（⏸ ▶ ▶▶）・需要バー、下＝道具バー、施設の一覧（未学習 → 学ぶへ / 配置待ち → 置く / 配置済み → 稼働率）、住民の声、調べたマスの情報。
- `CityCanvas`（three.js、遅延読み込み）：地面・水・林・道路・区画の色・建物（段階と種類で高さと色）・施設の建物・範囲の輪・配置の下見・車・影・昼夜。WebGL が無ければ代わりの案内を出す。
- 施設の建設を決めた直後は、その施設の配置を道具に選んだ状態にする。
