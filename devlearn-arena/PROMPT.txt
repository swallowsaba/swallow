devlearn-arena/DESIGN.md と devlearn-arena/REWORK.md を読み、未完了の項目を上から順に実装しろ。
DESIGN.md は 3D 版に差し替えられている。過去の「SVG で描け」「3D ライブラリを入れるな」「斜め45度にしない」はすべて撤回された。
three.js（と @react-three/fiber, @react-three/drei）を入れて、Cities: Skylines II のような 3D の街として作り直せ。
外部から 3D モデルは取らず、形はコードで組み立てろ。GitHub Pages で動くこと。
太陽光と影、夜に灯る窓、街路樹と街灯と車と人、縁石と車線のある道路を入れろ。
建物はパラメータから組み立て、1棟に窓を40枚以上、屋上設備を2つ以上、基壇とセットバックを持たせろ。
同じ形は InstancedMesh でまとめ、描画呼び出しを200以下に保て。
状態から街を導く部分は純粋関数にして、乱数ではなく seed から決め、テストしろ。
街は学習者が設計し（勝手に配置しない）、コマンドの成功でもクイズの正解でも必ず育つこと。
終わった項目は REWORK.md のチェックボックスを [x] に変えてコミットしろ。
各項目ごとに devlearn-arena で npm run typecheck と npm run lint と npm run test を通し、落ちたら自分で直してからコミットしろ。
playwright は実行するな。
確認を求めず、報告のために止まるな。全項目が [x] になるまで進めろ。
全部終わっていたら ALLDONE とだけ出力して終われ。
