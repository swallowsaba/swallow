# Security Policy

## Scope

RAW Studio runs entirely in the browser. It has no server component, and it
never uploads your images or edits anywhere — all processing and storage
(IndexedDB) happen locally on your device.

## Reporting a Vulnerability

If you discover a security issue (for example, a way that a crafted image file
could execute code, or a cross-origin isolation bypass), please **do not open a
public issue**. Instead, use GitHub's private
[Report a vulnerability](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
flow on this repository, or contact the maintainers directly.

Please include reproduction steps, affected browsers, and the impact. We aim to
acknowledge reports within a few days.

## Supported Versions

Only the latest released version on the `main` branch is supported.
